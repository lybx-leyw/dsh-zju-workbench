# 窄屏 / 手机端布局：改动前后对照

同一台实例（DSH 0.2.2-rc.1 + `dsh-pocket@2.12.0` 已装配）、同一份 profile、
同一账号、同一视口与主题。`before-*` 是改动前的构建，`after-*` 是本次改动后的构建。

复现环境：Chromium（Playwright 自带），移动档 `isMobile: true, hasTouch: true`。
读数在 `before-measurements.json` / `after-measurements.json` 里，可直接对比。

## 1. 手机 390×844：首页正文被压成 0 宽

第三方的移动端样式（`dsh-pocket`）把网格压成 `1fr 0 0` 之后，宿主的主内容列
仍落在第 2 轨 —— 而那一轨是 0。页面只剩背景色。

| | 主内容列 `[x, width]` | 读数 |
| --- | --- | --- |
| before | `[390, 0]` | 完全不可见 |
| after | `[51, 339]` | 占满导航栏右侧的整块宽度 |

- `before-home-390x844.png` / `after-home-390x844.png`

## 2. 手机 390×844：点开侧栏抽屉后主内容只剩 110px

改动前，产品层「侧栏让出 51px」的样式在抽屉态也生效，网格被锁成
`229px 110px 0`，主内容只剩一条。改动后抽屉态不再套那条规则，网格回到
`339px 0 0`，主内容仍是整块。

| | 网格 | 主内容列 |
| --- | --- | --- |
| before | `229px 110px 0px` | `[280, 110]` |
| after | `339px 0px 0px` | `[51, 339]` |

- `before-drawer-open-390x844.png` / `after-drawer-open-390x844.png`

## 3. 手机 390×844：论文页正文被压成一条竖排字

树栏 190px 的地板 + 落地页的横排，让正文只剩 **84px** —— 「惟学无际」竖着排。
改动后两栏竖着叠，落地页占满 307px 并恢复正常行文。

| | 树栏 | 落地页 | 排布 |
| --- | --- | --- | --- |
| before | `[51, 190]` | `[241, 84]` | `row` |
| after | `[51, 307]` | `[51, 307]` | `column` |

- `before-paper-390x844.png` / `after-paper-390x844.png`

## 4. 手机 390×844：笔记页正文被挤出容器

文件树 190px + 正文 `min-width: 400px` 超过 390 的屏宽，正文整块落到容器外
（x=241、右端 641），被 `overflow:hidden` 裁掉，右侧一片空白。改动后两栏竖排，
正文回到 307px 宽。

| | 文件树 | 正文 |
| --- | --- | --- |
| before | `[51, 190]` | `[241, 400]` |
| after | `[51, 307]` | `[51, 307]` |

- `before-notes-390x844.png` / `after-notes-390x844.png`
