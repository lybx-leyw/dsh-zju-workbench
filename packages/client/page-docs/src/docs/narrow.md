# 窄屏 CSS 覆盖与工效学

这一页回答一个问题：**窄屏上到底改了哪些 CSS，改完还看得舒服吗。**

完整清单（逐项读数、改前 / 改后截图、已知限制）在仓库
`docs/narrow-css-overrides.md`；这一页是查表用的摘要。

## 口径

- 视口：360×640、390×844、430×932、844×390（横屏）、768×1024、1440×900
- 主题：浅色 + 深色分别校验
- 阈值：`docs/contributing/skills/human-factors-screen-design/` 的
  `repo-profile.md` 与 `checklist.md`
- 命中区按**可点范围**算（WCAG 2.5.8），不是可见图形

## 窄屏覆盖的三条原则

1. **先让位，再缩，最后才取消。** 文档页右目录 ≤1100 让位、左目录 ≤860 变窄、
   ≤640 变浮层；笔记 / 论文两页 ≤700 从横排改竖排。取消是最末一手。
2. **改排布方向，不改「谁该收起」。** 树栏收不收归用户与导轨那只鲸鱼；
   断点只负责「并排挤不下时竖着叠」。
3. **手指的点法要单独算。** 桌面 26–37 px 的图标格在触屏上相邻只差 28–33 px。
   命中区用透明 `::after` 撑开，图形与排布一像素不动。

## 覆盖点一览

| 区域 | 覆盖点 | 宽屏 | 窄屏 |
| --- | --- | --- | --- |
| 外壳 | 导轨宽度 | 51 px | 51 px（不压缩） |
| 外壳 | `.zw-content` 内边距 | `43px 48px` | `25px 19px` |
| 外壳 | 侧栏「让出 51 px」 | 生效 | 抽屉态不生效 |
| 外壳 | 账户 / 设置入口 | 导轨底部 | 抽屉底部（不搬） |
| 文档 | 左侧目录 | 常驻 229 px | 浮层 258 px，默认收起 |
| 文档 | 右页内目录 | 186 px | 隐藏（≤1100） |
| 文档 | 正文行宽 | ≈56 汉字 | ≈20 汉字 |
| 文档 | 目录条目行高 | 29 px | 39 px |
| 笔记 | 三栏 | 横排 | 竖排（≤700） |
| 笔记 | 正文地板宽 | 400 px | 0 |
| 论文 | 树栏 + 正文 | 横排 | 竖排（≤700） |
| 论文 | 收起态窄条 | 28 px 竖条 | 横条（入口不删） |

## 命中区（`pointer: coarse`）

| 目标 | 图形 | 改前 | 改后 |
| --- | --- | --- | --- |
| 鲸鱼（收起 / 展开侧栏） | 23×17 | 24×18 | **44×45** |
| 导轨导航项 | 37×37 | 36×37 | **50×43** |
| 笔记顶栏 | 30×30 | 30×30 | **33×42** |
| 笔记栏头 | 26×26 | 26×26 | **28×44** |
| 论文栏头 | 26×26 | 26×26 | **28×42** |

相邻两格中心距只有 28 px，所以不是一律撑到 44：各扩 9 会让两块命中区重叠，
**点错了没有任何提示**，比略小更糟。取 8 得到 42、彼此留 2 px 明确间隔。

## 两个「按钮自相矛盾」的坑

这两条都是同一类错误：**桌面上的机制搬过来了，窄屏上的可见性前提没跟着搬。**

### 文档目录永远打不开

鲸鱼按 `navOpen` 显示「收起 / 展开文档目录」，而窄屏样式表写着
`.zwd-nav { display: none }`。于是点来点去目录都不出现，文案却一直在翻。

改法：窄屏下目录改成盖在正文上的浮层，`navOpen` 初值跟着视口走（手机收起、
桌面展开），挑完一篇浮层自己让开。

### 账户入口被搬到视口外

搬移规则的前提是「侧栏是常驻列」。抽屉态下宿主给侧栏
`transform: translateX(-280px)` 做开合动画 —— `transform` 会让祖先成为
`position: fixed` 的**包含块**，`left: 6px` 于是相对浮层再左移。实测 390×844 下
入口 rect 是 `[-221, 798, 264, 40]`，整个在视口外。

改法：整段搬移挂 `html:not(:has([data-sidebar-drawer]))`，抽屉态留在宿主原生位置。

## 已知限制

| 项 | 现状 | 影响 |
| --- | --- | --- |
| 文档页正文 | 13.5 px（长文口径要 ≥14） | 手机上读长文略吃力 |
| 11 px 元信息 | 多处 | 低于 16′ 下限，仅装饰性信息 |
| 横屏导轨 | 454 px 内容 / 390 px 可视 | iOS 横屏时底部两项要滚一下 |
| 登录态页面 | 未量 | 学习页课程树、题库出题表单未覆盖 |
| 原生发送按钮透出 | 与窄屏无关 | 外壳分层问题，1440 也有；不属于本清单 |
