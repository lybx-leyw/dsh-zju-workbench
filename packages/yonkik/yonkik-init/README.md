# @lybx-leyw/dsh-zju-yonkik-init

YONKIK 的**初始记忆**：一份脱敏后的站点侦察知识库，用来给新机器铺底。

## 它是什么

`memory/` 里是 132 个浙大站点的接口与鉴权手册，每站三份文件：

| 文件 | 内容 |
| --- | --- |
| `wiki.md` | 鉴权链路、接口表、坑与判据（**主要价值在这里**） |
| `endpoints.json` | 端点清单：路径、方法、鉴权方式、实测状态 |
| `site.json` | 元数据：状态、鉴权类型、限流、阻断理由 |

外加顶层 `_dir.md`（一行式目录）、`_playbook.md`（跨站可迁移经验）、
`_sso.json`（CAS 家族归类）、`_index.json`（路由索引）。

## 用法：**自动**，不需要你做什么

装上本包，第一次启动时记忆区若为空，它会**自动**把内置记忆铺出去，
并写一个标记 `<记忆区>/.yonkik-initialized`：

```json
{
  "initializedAt": "2026-11-24T12:50:46.996Z",
  "seedVersion": "0.1.0",
  "seedFiles": 396
}
```

**打过这个 flag 就不再重新初始化** —— 之后每次启动只读一次标记就返回，
一个文件都不写。

想手动介入时（一般不需要）：

```bash
yonkik init              # 幂等：已初始化则什么都不做
yonkik init --dry        # 只报告会做什么
yonkik init --force      # 强制重铺（会覆盖已有记忆，危险）
```

## 三道闸，保证只铺一次、且不覆盖你的东西

| 闸 | 判据 | 作用 |
| --- | --- | --- |
| 标记 | `<记忆区>/.yonkik-initialized` 存在 | 最省事的一条：直接跳过 |
| 内容 | 至少有一份站点的 `wiki.md` | 你从别处带来的记忆不会被覆盖 |
| 幂等 | `seed()` 内部再判一次 | 双保险 |

### ⚠️ 什么**不算**「已有记忆」

`yonkik-tool` 启动时会 `seedDefaultSites()`，把 zjuers 的 98 个站点以
`status: "pending"` 写进 `sites/_index.json`。那只是一张**待探索的路由表** ——
没有 wiki、没有接口、没有鉴权结论。

如果拿它当「已初始化」，结果就是：工具先建空索引 → init 判定「已有 98 个站」→
跳过 → **一个 wiki 都没铺**，而界面上看不出任何异常（工具照常能跑，只是什么都不知道）。

实测过这个顺序，bundle 序里 tool 在 init 之前。所以判据是**有没有真知识**
（至少一份 `wiki.md`），不是「索引里有没有行」。

## ⚠️ 记忆是过去的实测，不是当前事实

**这份记忆来自另一台机器、另一个时间点。** 里面每一条「已验证」都只说明
**当时**在**那台机器**上成立。

环境会变：站点改版、接口下线、鉴权方式调整、学校换系统、网络位置不同 ——
任何一条都能让一条「已验证」的结论失效。

所以：

1. **拿它当假设，不当结论。** 动手前用一次真实请求确认。
2. **发现不符就以实测为准**，并把记忆改掉。
3. **「已验证」不是承诺**，它记录某次探索的结果，不担保今天仍可用。

这条警告也写在内置的 `MEMORY.md` 开头，`yonkik init` 之后用户第一眼就能看到。

## 幂等性

`seed()` 只在记忆区**没有实质内容**时才铺：

- 有站点的 `wiki.md` 或 `MEMORY.md` → 跳过
- 目录不存在 / 空 / 只有 `_index.json`（路由表）→ 铺种子

重复跑、以及用户改过记忆之后再启动，都不会覆盖。

## 脱敏

这份记忆由 `scripts/yonkik-export-seed.mjs` 从真实记忆区导出，导出时剔除：

- 登录态：`state.json`（cookie）、`token.json`（JWT）
- 个人数据：学号、真名、`my-courses.json`（选了哪些课）
- 本地痕迹：绝对路径 `C:\\Users\\<用户名>\\...`
- 「已验证实例」整节（记的是探索者本人上过哪门课、哪位老师）
- 二进制：截图、PDF 教材、HTML 快照

导出脚本可重复运行，脱敏规则是**同一套**，便于下次重新导出时复核。

## 为什么单独成包

记忆内容是**可替换的产品数据**（3 MB），跟着工具版本走会让工具包臃肿，
也让「换一份种子」变成改代码。工具里用同级相对路径取它
（`packages/yonkik/` 不在 npm workspaces 里，裸包名解析不到）。
