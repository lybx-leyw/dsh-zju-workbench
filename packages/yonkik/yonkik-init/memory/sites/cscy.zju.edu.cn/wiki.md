## 可检索的数据库清单（免登录可读，从 `preRequest2.html` 提取）

`preRequest2.html` 是一个**免登录的表单页**，把全部可勾选项都渲染在 HTML 里。分类如下：

**理工农医**：SCI(SCIE) 英文版（收录/引用 + JCR 影响因子/JCR 分区/中科院分区升级版 + 自引他引）、
EI 英文版、CPCI-S 英文版、CSCD 中文版、MEDLINE 英文版、CA plus。

**社科**：SSCI 英文版（同 SCI 的 JCR/分区选项）、AHCI 英文版、CPCI-SSH 英文版、
CSSCI 中文版、INSPEC 英文版、人大复印资料全文数据库。

**综合**：Web of Science 核心合集、ESCI 英文版、SCOPUS、万方、维普、
中国学术网络出版总库、IEEE、CNKI（会议论文/CNKI/CNKI 引用）、ABI、
InCites 学科百分位、MathSciNet(MR)、专利法律状态（含专利法律状态证明）、ESI 收录、高被引论文、热点论文。

> 还支持**自定义「输入数据库名称」**一项 + 中文/外文文献数量，说明可临时约其它库。

## 查收查引的关键事实（免登录可读原文）

### 处理时限与交付
- **2-3 个工作日**（`zdNoticeDesc` 第 4 条、`libweb` 服务页一致）；篇数多或高峰期延长。
- 只提供**纸质版原件（一式两份）**，**「暂不提供拍照、扫描等服务」**（第 3 条）。

### 费用规则（直接回答 CC98 的追问）
- **「已按委托人要求完成的检索证明，即需缴纳相应检索费用」**（第 7 条）
  → 即**开具即计费**，不是领取才计费。
- 取消委托：**必须及时告知处理馆员或值班人员**（第 7 条）。
- **「请勿重复提交委托」**；已提交未回复的，先打电话确认状态（第 8 条）。

### 付款方式共 5 种（`libweb/55976` 原文）
1. **现金**——仅限紫金港主馆
2. **校内转账——4 种路径**
   - 财务处转账（推荐）：需填图书馆指定的校内经费卡号（具体卡号属内部财务信息，此处不记）
   - 一卡通网上自助转账（计财处综合财务管理平台 → 预约报账 → 结算点转账 → 结算点「图书馆」→ 用途「查新费/检索费」）
   - 委托图书馆转账（需授权办公室老师办理，具体经办人与工号属内部信息，此处不记）
   - 现场拍卡经费转账（仅紫金港主馆）
3. **校园一卡通刷卡**——仅紫金港主馆 / 玉泉图书馆
4. **支票**——抬头「浙江大学」，内容「查新费」或「检索费」
5. **银行汇款**——帐户名 浙江大学，开户行为学校对公账户（具体账号与行号以官方页面为准，此处不记）；**明确不要用 ATM/支付宝/微信**

> 两条重要限制：
> - **校内报销**：现金缴费**不能**开本校抬头发票 → 不能校内报销，**建议走校内转账**。
> - **校外报销**：需提供单位全称与税号，否则只能开个人/委托人姓名发票 → **不能报销**。

### 其它必读条目
- 申请必须填**作者与联系人的真实姓名 + 具体联系方式**（第 1 条）；本档不记录任何真实姓名与联系方式。
- 不确定查哪些库，先打电话咨询（第 2 条）——避免多花钱。
- 一单多文献默认**同库合并开具**；要分开就拆单，或委托后电话联系馆员（第 5 条）。
- 影响因子可出 **JCR 影响因子 / JCR 分区 / 中科院分区（升级版）**，年份限 **2022、2023、2025**（第 6 条）。

## 坑

1. **`/` 是 301 到 `/login.html`**，直接打 `/` 会多一跳；`server: Jetty(6.1.x)`。
2. **`zdServiceDesc.html` 是 gb2312**，而 `zdNoticeDesc.html` / `preRequest2.html` 是 UTF-8 ——
   **同站内编码不一致，必须逐页判**（用 `content-type` + meta 双读，或一律先试 gb18030 再回退 UTF-8）。
3. **`preRequest2.html` 免登录但 103KB**：它是预申请**表单**，不是提交结果页。
   可以读全部可选项，但**不要提交**（含「登录密码」字段，提交即注册）。
4. **登录页有两个认证入口**：「系统认证」（本站账密）与「统一认证」（CAS）——
   校内用户走统一认证；校外用户需先注册。这两条路的账号体系不同。
5. **`libweb/55976` 的「服务委托申请提交（点这里）」指向 `cscy.zju.edu.cn`** ——
   门户与系统是两个域，别在门户上找提交按钮。
6. 页脚「图书馆统一认证」的链接指向 **`system.lib.whu.edu.cn`**（武汉大学）——
   这是**厂商默认模板未改**的残留，不是浙大站点，不要跟着跳。
