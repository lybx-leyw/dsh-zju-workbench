## 坑

1. **`/` 不是首页，301 到 `/genee/`** —— 直接用 `https://yqgx.hic.zju.edu.cn/` 会先吃一个 301。
2. **`/genee/` 与 `/lims/` 是两套完全不同的 app** —— 门户免登录，业务要登录。所有数据在门户，所有操作在 lims。
3. **仪器详情页在 `/genee/equipment/{id}`，而预约按钮指向 `/lims/!equipments/equipment/index.{id}.reserv`** —— 同一个 id 两个不同路径前缀，别混。
4. **目录分页是 `?st=0/15/30/45/60`**（offset 步进 15），不是 `page=N`。
5. **三个栏目是空的**：规则制度/服务指南/常用下载都「共 0 条信息」。不要以为是抓取失败。
6. **收费标准的 HTML 结构很脏**：公告表格直接平铺在详情页末尾，无 table 包裹（「制样：150/样 送样测试：1500/样/元素 …」连成一段）。要正则抠。
7. `.hic` 域可能对校外有限制 —— 本次从当前网络**完全可达**（42–206ms）。若不可达先怀疑本机代理（见 `_playbook.md` 代理 7993 条）。
