# 统一身份认证 zjuam.zju.edu.cn

## 定位（2026-11-22）

全校 **CAS** 认证入口。**这是认证基础设施，不是业务数据源**——它本身不产出任何校园数据，只负责发放会话。

- `GET /cas/login` → 200，19,009B，标题「统一身份认证平台」。
- `GET /` → 200 但是 162B 的错误页；正确入口是 `/cas/login`。

## 登录表单结构（已完整记录）

| 字段 | 说明 |
|---|---|
| `username` | **职工号/学号/邮箱/别名** 四种标识都接受 |
| `password` | 密码 |
| `authcode` | **验证码** |
| `rememberMe` | 记住登录（checkbox） |
| `execution` | 一次性令牌（形如 `<uuid>_<base64 JWT>`），随页面下发 |
| `_eventId` | 固定 `submit` |
| `ys` | 固定 `5` |

## 结论

- 用户名字段接受多种标识，这一点对「为什么有的站用学号、有的用邮箱」有解释力。
- 提交需要 `execution` 一次性令牌 + **验证码**，验证码是**硬性人工环节**。
- 因此本库**不做自动登录**：不提交表单、不识别验证码、不缓存令牌、不保存凭据。

## 与其他站的关系

zdbk / courses / classroom / pintia / s1 等站的登录都会跳到这里（CAS 或 CAS-OAuth2）。各站的跳转链已在各自档案里逐跳记录，便于日后持凭据时从最后一跳接续。
