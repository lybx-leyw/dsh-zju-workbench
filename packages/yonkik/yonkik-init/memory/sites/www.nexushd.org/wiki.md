## 一句话结论 + 安全声明

**这是个 Invite/注册制的校内 PT 站，匿名下只有登录页、注册页、FAQ、robots 四个公开页，其余全部跳登录。**

**安全声明（本页最重要的一节）**：

- **未登录。** 用户无 NexusHD 凭据（`campus-sso` 是一卡通，不覆盖 PT 私有账号）。
- **未注册。** 用户明确要求「绝不注册」。注册是写操作，且小号会被连主号一起封。
- **未下载 / 未做种 / 未兑换 / 未求邀。** 这四件事都会动积分、分享率或账号状态，任一越界都可能连带封 IP。
- **只读了 6 次**：`/`（含 301）、`/login.php`、`/signup.php`、`/faq.php`、`/robots.txt`、`/torrents.php`（唯一一次触业务页，只为确认「需登录」）、`/torrentrss.php`（为确认 passkey 机制）。
- **robots.txt = `Disallow: /`（全站禁爬）**，所以即便只是公开页，也已压到最低次数。

**这是本组最需要克制的一站。宁可只有一页 wiki，也不越界 —— 已完成。**

## 三入口的差异

| 入口 | URL | 实测 |
|---|---|---|
| 登录（校网） | `https://www.nexushd.org/login.php` | 200，本机可达（校网/公网 IP 均可解析） |
| 登录（校外 IPv6） | `https://v6.nexushd.org/login.php` | **`getaddrinfo ENOTFOUND`** —— 本机 DNS 解析不到该子域 |
| 注册（仅限校网） | `https://www.nexushd.org/signup.php` | 200，但邮箱白名单限制 `@zju.edu.cn` / `@intl.zju.edu.cn` |

**`v6.nexushd.org` 解析失败是本机条件问题，不是站点问题。** 它要么只有 AAAA 记录（本机无 IPv6 出口），要么在校内 DNS 才有。**标 blocked，不断言它挂了。**

这也印证了 CC98 帖 6373357「要用 WebVPN 才能上 98? 而且 NexusHD 打不开惹」—— 校外访问确实需要 IPv6 通道，这是设计使然。

## PT 规则要点（从公开 FAQ 读出的）

这些是**公开 FAQ 的原文内容**，不是推测：

**分享率（FAQ 2.5）**
> 「分享率是你的上传量除以下载量得到的结果，即 分享率 = 上传量 / 下载量。」

提高上传量的正当方式（FAQ 原文列出）：
1. 发布符合规则的资源
2. 关注**促销种子**（FAQ 3.1）
3. 下载后持续做种
4. 下载后持续做种以获得**魔力值**，然后在魔力值系统内用魔力值兑换上传量

**用户等级（FAQ 2.6）**
- `Peasant`：被降级用户，**有 30 天时间提升分享率，否则账户被禁用**
- `User`：新用户默认
- `Power User`：得 1 个邀请名额、可直接发布种子、可查看 NFO/用户列表/排行榜
- `Elite User` 及以上：**封存账号后不会被删除**
- `Crazy User`：2 个邀请名额 + 可匿名发布
- `Insane User`：可查看普通日志

**这解释了 CC98 帖 6322801「刚开始用，为什么告诉我下载时间正无穷」**：新号下载量 > 0 而上传量为 0 时，`分享率 = 0/x = 0`，NexusPHP 会显示为无穷/极大值警告。这是**新手分享率机制的预期行为**，不是 bug。

**恢复路径线索（FAQ 6.1-6.5）**：不要马上下载新发布的种子 / 限制上传速度 / 限制同时连接数 / 限制同时上传数 / 等待一会。这是提升下载速度的建议，实际也服务新手期。

### 额外发现（CC98 没提到、但对复用很有用）

1. **登录页有「50 次连续登录失败将导致你的 IP 地址被禁用」+ 实时计数器「你还有 [50] 次尝试机会」**。→ **任何自动化试密码都是高危行为**，一次错配就可能烧掉 IP。这是我没有尝试任何登录的根本原因。
2. **登录页有一个公开的求助留言框**（`GET /shoutbox.php`，字段 `shbox_text`）。但提交是写操作，未碰。
3. **「被禁用户自助解封入口」存在** —— 说明封禁不是终局，有申诉通道。
4. **注册邮箱白名单是硬限制**：`@zju.edu.cn` 或 `@intl.zju.edu.cn`，两者都不是则注册不了。

## 坑

1. **`/torrentrss.php` 返回 HTTP 200 但 body 是 `invalid passkey`（15B）。** 用状态码判断会以为「RSS 免登录可用」。**必须看 body。** 这是 NexusPHP 的通用坑。
2. **`robots.txt` 是 `Disallow: /`，全站禁爬。** 这条要写在任何复用脚本的头部，否则下一个人会以为可以写爬虫。
3. **`v6.nexushd.org` 在本机 `ENOTFOUND`。** 不要判成「站点挂了」，是 DNS/IPv6 条件问题。
4. **`https://ww%57.nexushd.org/login.php`** 出现在首页链接里 —— 这是 `%57`=`W` 的 URL 编码混淆（同一 host 的变体写法）。别以为是第三个域名。
5. **50 次失败封 IP 的计数器是实时的、显示在页面上。** 任何登录自动化前必须先人工确认凭据正确，**不要靠重试探索**。
6. **`sierra`…（不适用，本站非浙大系统）。**
7. **本机必须 `node:https`**（env 代理）。
8. **不要把 NexusHD 的「校网」理解成 CAS。** 它用**自有账号密码**（`takelogin.php`），`campus-sso` 一卡通在这里**用不上**。CC98 账号登录通道已标记「该功能已损坏」。

## 本次探了什么 / 刻意没探什么

**已探（6 次只读 GET）**：`/` · `/login.php` · `/signup.php` · `/faq.php` · `/robots.txt` · `/torrents.php`（仅确认 301）· `/torrentrss.php`（仅确认 passkey 机制）。

**刻意没探（写进 `endpoints.json` 的 unverified/blocked，标注原因）**：
- `POST /takelogin.php` —— 无凭据 + 50 次封 IP 风险。
- `POST /signup.php` —— 注册是写操作，用户明确禁止。
- `GET /details.php?id=` —— 遍历资源 ID 违反安全契约。
- `GET /download.php?id=&passkey=` —— 计入下载量，直接伤分享率。
- `GET /usercp.php` `/mybonus.php` —— 需登录，且魔力值涉及站规灰区。
- `POST /shoutbox.php` —— 写操作。
- `v6.nexushd.org` —— 本机解析不到，blocked。

**脚本**：**未写 `crawler.mjs`，这是有意的。** 这一站没有任何匿名可读的业务接口，写爬虫等于写一个「绕过登录」的工具，与安全契约冲突。`site.json` + `endpoints.json` + 本页 wiki 就是它的全部资产 —— **知道边界在哪，比有一把钥匙更有用**。

**如果将来用户提供了自己的账号并明确授权**：唯一正当的用途是读**自己**的 `usercp.php`（分享率/魔力值）与自己的种子列表。仍然不能遍历他人资源、不能下载（会动分享率）、不能兑换。`endpoints.json` 的 `blocked.howToUnblock` 已写明这个条件。
