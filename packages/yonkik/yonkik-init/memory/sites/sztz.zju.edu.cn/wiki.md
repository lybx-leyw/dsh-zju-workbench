## 概览

`sztz.zju.edu.cn` = **浙江大学大学生素质拓展数智平台**，主办单位是
**共青团浙江大学委员会 + 浙江大学学生素质拓展认证中心（校素拓）**。

它不是「团委活动报名网」，而是 **第二课堂 / 第三课堂的学分（素拓分）登记与审核系统** ——
即学生口中说的「二课」「素拓分」。

首页导航（免登录可见）：
`首页 · 项目总库 · 资料下载 · 答疑解惑 · 第二课堂成绩单 · 师生登录 · 管理员登录`

## 跳转到哪（134B 之谜）

`GET /` → 200，**142 字节**，全文：
```html
<html><title>正在跳转...</title><body><script type="text/javascript">location.href='https://sztz.zju.edu.cn/dekt/';</script></body></html>
```

→ **`/dekt/`**（`window.__basePath = "/dekt/"`，Vue3 + Element Plus + ECharts + xlsx SPA）。

> 顺带：`/robots.txt` 也返回这同一段 142B 跳转脚本，**所以本站实际上没有 robots 规则**。

## 鉴权

- **公开面（免登录）**：通知公告、答疑解惑、活动列表、项目总库、项目分类字典。
  实测**无 cookie 直接 200**，数据完整。
- **需登录**：第二课堂成绩单（`#/index/dektcjd`）、项目申报、审核状态、师生/管理员入口。
- 会话机制：前端启动 `POST /dekt/ctx`（HTML 上下文页）→ 下发 `SESSION` cookie。
  本站**不是** CAS 直连，登录入口在站内 `#/login`（可能再跳 CAS，未实测）。
- 另有 `open.zju.edu.cn` 的 Hiagent 客服 SDK（`appKey <appKey>`），
  是页面右下角智能问答浮窗，与本系统数据无关。

## 限流

- `/robots.txt` → 142B「正在跳转...」（同首页），**不是 robots 文件**。
- 无 `X-RateLimit-*` / `Retry-After`。
- 保守默认：**串行、间隔 ≥2s、并发 1**。本次未触发 429。

## 接口（详见 endpoints.json）

五条 verified，全 `GET`、全免登录、前缀 `https://sztz.zju.edu.cn/dekt`：

| 接口 | 用途 | 实测规模 |
|---|---|---|
| `/student/home/getTzggList?page=&limit=` | **重要通知**（含正文 HTML） | 20 条 / 75KB |
| `/student/home/getDyjhList?page=&limit=` | **答疑解惑**（问答对，已脱敏） | 10KB |
| `/student/home/getHdList?page=&limit=&date=` | 活动列表（带学分值） | 当天 56KB |
| `/student/home/getXmList?keyword=&nj=&page=&limit=&lx=1&finished=` | **项目总库** | count=100 |
| `/student/home/getXmBaseData` | 项目分类字典 | 6.8KB |

响应包格式：`{code:0, msg, extend, data, pageIndex, pageSize, totalPages, count}`。
`code:0` 是成功（与某些站的 `success:0` 类似，注意别按 HTTP 语义理解）。

### 字段速查
- 通知 `getTzggList`：`id / mc（标题）/ fbr（发布人）/ fbsj / nr（正文 HTML）/ fjmc（附件名）/ fjid`
- 答疑 `getDyjhList`：`mc / shzt.label · hfnr（回复 HTML）/ hfr（回复人）/ sfgk`
- 活动 `getHdList`：`mc / flowStartUser（发起单位）/ **zxfs（执行分数）** / **zdfs（总分数）** / hdkssj / bmkssj`
- 项目 `getXmList`：`mc / flowId:'xmsqFlow' / zxfs / zdfs / fzr（负责单位）/ lxdh`

## 「二课/素拓学分」的实证

不用猜，接口直接给：

1. **分类字典** `getXmBaseData` → `extend.xmflList`：
   ```json
   [{ "id": 1, "mc": "第二课堂", "sfdekt": true, "sfdskt": false },
    { "id": 2, "mc": "第三课堂", "sfdekt": false, "sfdskt": true }]
   ```
   `sfdekt` = 是第二课堂，`sfdskt` = 是第三课堂。**学生说的「二课」就是这里的「第二课堂」。**
2. **每个项目/活动都带学分值**：`zxfs`（执行分数）与 `zdfs`（总分数），如 `1.500 / 5.000`。
3. **通知正文直接讲学分审核规则**。原文（2026-10-10 那条）：
   > 各院级团委、直属团总支：现就 2026-2027 学年秋冬学期校院两级第二、三课堂项目审核时间通知如下。
   > 一、院级审核时间：学院（园）分别在 10月26日-11月2日、12月21日-12月28日完成前阶段累积项目的学院审核工作。
   > 二、校级审核时间：校素拓在 11月16日-11月23日、1月16日-1月23日内完成…
   > 学生如对校级审核结果有异议，应在每轮审核完成后的一周内向浙江大学学生素质拓展认证中心提出复核。
   > 联系人：<姓名> <电话>；<姓名> <邮箱>（校素拓）

**所以：这是「素质拓展学分（二课/三课）」的登记 + 院级/校级两级审核系统，不是活动报名系统。**
活动（`getHdList`）是**可以用来挣学分的项目载体**，报名/审核是流程，最终产出是学分记录。

## 坑

1. **`/` 返回 134–142B 别当成「站点空壳/挂了」。** 那是一个 JS 跳转页，真站在 `/dekt/`。首轮 triage 只看到 134B 很容易误判成死站。
2. **`/robots.txt` 也是那段跳转脚本。** 本站实际**没有 robots 规则**，别把它的内容当 robots 解析。
3. **`code: 0` 才是成功**（`{"code":0,"msg":"success"}`）。这与 HTTP 200、也与某些平台的 `success:0` 记法不同，按 `code` 判即可。
4. **多数已知公开业务使用 `/dekt/student/home/*`；公告还有 `/dekt/student/tzgg/ajaxList`，不该猜 `/dekt/api/*`。** 从 bundle 里搜 `/sys/*`、`/tenant/*`、`/monitor/*` 会搜到一堆**框架自带的多租户后台模块**（`/sys/user`、`/sys/role`、`/tenant/admin`…），那些不是学生业务面，也不会在未登录时给你数据——别在 bundle 里瞎试，直接看首页 XHR 更快。
5. **`getHdList` 的 `date` 参数是必填的**（决定「当天活动」）。不传可能回空或今天的默认值，未逐一枚举。
6. **`getXmList` 的 `lx=1` 是项目、`lx=2` 是活动分支（上游实现与匿名首屏支持），不是第二/第三课堂学分类别。** 没有做完整的 `finished` 参数矩阵，不用它推断每条活动的当前状态。
7. **答疑接口的脱敏是服务端做的**：`xh/xm/lxdh/yx` 都是 `****`。**不要以为掩码是前端遮的**去试着拿原始值——那不是只读探索该做的事。
8. 页面加载会打 `open.zju.edu.cn` 的 Hiagent 客服接口（`get_websdk_config`）。那是第三方客服 SDK，**与本站数据无关**，抓包时排除掉。

## 二课平台校正（2026-11-22）

**本 wiki 早前把 sztz 记为「400 类空壳」，实际它是「浙江大学大学生素质拓展数智平台」的 SPA，只是入口不在根路径。**

| 路径 | 结果 |
|---|---|
| `https://sztz.zju.edu.cn/` | 200，**142B 跳转页**（`location.href='/dekt/'`） |
| **`https://sztz.zju.edu.cn/dekt/`** | **200，3,161B，title「浙江大学大学生素质拓展数智平台」** |
| `/common/file/download` | 142B **跳转页**（裸调无参数时，不是文件也不是 404） |

**根路径 142B 这个特征很重要**：看起来像「站点是空壳/已下线」，其实是 SPA 的跳转壳。
判据：正文含 `location.href=` 就是跳转页，不要据此判死。
