## 这是什么

浙大后勤集团门户。**对学生最有用的是「日常通知」里的停电/停水/食堂通知** ——
寝室停电是那种「不知道就白等一天」的信息，而它只发在这里。

结构：集团概况 / 新闻中心（要闻·部门动态·后勤追光）/ 党团建设 / **通知公告**（日常通知·公示公告·采购公告）/ 部门黄页。

## 列表结构坑（本页最重要）

两个坑叠在一起，导致第一版脚本一条都抓不到：

### 坑 1：日期是拆成两段写的

```html
<a href="../info/1036/104067.htm" class="a flex" title="关于11月22日玉泉校区部分区域停电的通知 ">
  <div class="time">
    <h3>19</h3>        <!-- 日 -->
    <h6>2026.11</h6>   <!-- 年月，点号分隔 -->
  </div>
  <h4 class="l1 h4s1">关于11月22日玉泉校区部分区域停电的通知</h4>
</a>
```

- 页面里**根本没有** `2026-11-19` 这种整串日期，按整串正则抓 → 0 条。
- 年月是 `2026.11`（点号），不是 `2026-11`。
- 要拼成 `2026-11-19` 得自己 `h6.split('.')` + 补零 + 拼 `h3`。

### 坑 2：标题在 `title` 属性里，不在标签文本里

`h4` 里虽然有文字，但**带尾随空格**；`title` 属性才是干净的那份。用 `title="..."` 取。

### 坑 3：列表容器是 `ul.list5`

页面上有多个 `<ul>`（导航、面包屑），必须锚定 `<ul class="list5">` 之后的区间，
否则会把导航链接当通知条目。

## 一个容易被忽略的细节：一半条目是微信外链

「日常通知」里约 **1/3 的条目 href 指向 `mp.weixin.qq.com`**（食堂推广、烹饪课报名这类）。
`crawler.mjs` 已经把 `external: true` 标出来了 ——
**这些内容本站抓不到正文**，只能给出外链。判断实际有用的停电通知时，优先看 `external: false` 的那批。

## 只读边界

`notices` / `article` 都是 GET。不提供报修提交、投诉、订餐等写操作。
