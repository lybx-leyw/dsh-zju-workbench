## 坑

1. **`https://` 直接 ECONNREFUSED，只能 `http://`** —— 与 `ms.zju.edu.cn`、`we.zju.edu.cn` 同类。
   可达性判定必须先试 http。
2. **`c86057a3024419/page.htm` 这种「栏目 id + 文章 id」拼出来的 URL 会回
   「访问地址无效，错误的栏目参数！」**（2,321B）。真正能访问的是首页给的完整链接。
   → 别自己拼 Webplus 的文章 URL；从列表页 href 取。
3. **`c86057/list.htm` 回 200 但 0 条** —— 栏目 id 单独用不对（同类 Webplus 陷阱，参见 service 的 `parentCategoryId`）。
4. 与 `libweb`/`bksy` 同属 Webplus 站群，文章 URL 规律一致：`/YYYY/MMDD/c<栏目>a<文章>/page.htm`。
5. 首页有 `使命2 --> 愿景 --> 实验安全 -->` 这类**未渲染的模板注释残留**，抓正文时要剥。
