# 全校检索 s.zju.edu.cn

## 搜索可用（2026-11-22）

- `GET https://s.zju.edu.cn/search/all.do?words=<关键词>` → 200，51,740B，标题「搜索_全部」，有分页。
- HTTP 同路径 301 到 HTTPS。
- 发现路径：`zhfw.zju.edu.cn` 页面里搜索框的 form action 就指向这里——综合服务网没有自己的搜索后端。

**检索质量**：标题按字面匹配。搜「校历」会返回标题被拆成「校 历」「校 印」的结果，属浅层检索，不能当语义搜索用。

**边界**：只验证入口与样例，不做批量检索；结果里的 `10.203.3.207:8080` 是内网地址，本环境不可达。
