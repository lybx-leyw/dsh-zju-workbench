---
> **这是 CC98 调研挖出的新系统，官方站群导航里没有收录。**
> 它跟 `www.life.zju.edu.cn` 的「班车查询」是**两套不同系统**：
> - `life/busQuery` = 只读时刻表（无余票、无预约）
> - `car.zju.edu.cn` = **真正能预约、能看实时余票、有违约机制**的那套

## 概览
uni-app 打包的 H5（Vue2 + webpack，title「浙大校车」），走浙大 CAS OAuth2。
用户数据里 `userType:1`（普通用户）、状态「正常」。页头有 **「温馨提醒:违约记录达到3次后,预约资格将被取消!」**。

功能：选起终校区 + 日期 → 查班次（**含实时余票**）→ 预约 → 上车点「确认上车」→ 可退票。

## 鉴权（纯 CAS，一卡通即可）
```
GET  http://car.zju.edu.cn/pages/index/login
  → 302 https://zjuam.zju.edu.cn/cas/oauth2.0/authorize
        ?response_type=code&client_id=NgRUUG0GFEOUjsV3Vc
        &redirect_uri=http://car.zju.edu.cn/pages/index/login
  → CAS 登录页（#username / #password / #dl，验证码 disabled）
  → 302 /cas/oauth2.0/callbackAuthorize?ticket=ST-...
  → http://car.zju.edu.cn/pages/index/login?code=ST-...
  → 前端 POST /platform/weChat/zdLoginCode → {accessToken(UUID), tokenType:'bearer', expiresIn:99999}
```
**campus-sso 一卡通可直接登录，验证码当前关闭。** token 存 localStorage，不在 cookie 里。

## 接口（详见 endpoints.json）
响应统一 `{success:0, msg:'成功', count:0, data:[...]}` —— **`success:0` 是成功**，别当错误。
全部 `POST /platform/*`，参数走 form body。

| 接口 | 用途 | 关键参数 |
|---|---|---|
| `/platform/car/station/select` | 6 个校区列表 | 无 |
| `/platform/ticket/search` | **查班次 + 实时余票** | `destinationName` `originName` `time` |
| `/platform/appHome/reserveTicket` | 我的预约 | `resource=home` |
| `/platform/appHome/userInfo` | 用户信息 | 无 |
| `/platform/appHome/message` | 通知 | 无 |

### ticket/search 的字段语义（重要）
- `seat` = **实时剩余座位**（life 的 busQuery 完全没有这个能力）
- `originName` = **具体站点名**，不是校区名。如「玉泉校区三舍西侧（前往各校区）」「玉泉校区教十二北面」「玉泉校区教十一南面」
- `bcName` = 班车名（教师1号班车…），`bid` = 班车 id，`lid` = 线路 id
- `originTime` = 发车时间，`destinationTime` = 到达时间（实测多为 null）
- `estimate` = true 表示该趟时间为估计值
- `stationStartNo` / `stationEndNo` = 该车在此区间的站序

**参数要用校区名（紫金港校区/玉泉校区/…），不是站点名。** 传校区名后返回的 originName 才是具体站点。

## 只有 6 个校区，没有海宁/舟山
`station/select` 返回：紫金港、玉泉、西溪、华家池、之江、湖滨。
海宁国际校区在**另一套系统**（国际校区微后勤，`https://www.intl.zju.edu.cn/my-zju/`），
且 CC98 实测「班车需要在国际校区申请入驻才能约」「学号不在他们档案里约不了」。
舟山（海洋学院）班次极少，CC98 建议公共交通/自驾。

## 违约机制（官方 + CC98 交叉验证）
- **3 次违约 → 取消预约资格**（系统页面原文）
- **什么算违约**：预约了但没点「确认上车」（上车后要在 App 里点确认，忘了就算）。CC98 上这是最高频的踩坑点。
- **系统故障也算**：2026-11 系统崩过几次，打不开确认界面 → 被强制记违约（多个帖子）。遇到这种情况**先点「退票」**（可避免违约），而不是干等。
- **申诉**：有申诉入口（CC98：「点进班车预约，最下面三个东西，按最右边那个」），写检讨可清零，有人实测「第二天就给我清零了」。
- 违约记录按学期清（CC98：「那学期结束了之后看不到违约记录了」）。

## 坑
1. **别把它和 life 的班车查询搞混**：life 只有时刻表，car 才能预约+看余票。
2. `success:0` 是成功，不是失败。这套接口的成功码是 0。
3. **预约不是必须的**（CC98 大量实测）：司机多数不查，有座就能上；但教师班车「未预约只能在末站（风雨操场学生开放点/东二门）上车」，预约了才能任意站点上车。
4. **晚 8 点规则**（CC98 高频提及，官方未记载）：**前一天晚上 8 点之后，学生可以不受预约码限制预约次日的教师班车**。这正是「预约码」只在提前预约时才卡人的原因。
5. 余票 0 不一定坐不上：班车约 48 座但只放 30 个预约位（CC98 说法，未在接口验证），现场常有空位。
6. CAS 登录后 URL 带 `?code=ST-...`，token 由前端换；纯 HTTP 复现要自己走完整 OAuth2 code 流程。
7. **这是写操作密集的系统**，本 YONKIK 只探了只读接口（查询/用户信息/预约列表）。预约、退票、申诉均为写，未调用。

## 与官方口径的关系
- 后勤集团页说的「预约流程：浙大钉→浙江大学平台→搜索班车预约」，实际调用的就是本系统的接口
  （浙大钉里的班车预约很可能是本系统的 iframe/H5 封装，CC98 上大量「浙大钉班车预约打不开」的抱怨与之吻合）。
- 官方说「本科生凭院系下发的预约码」——**CC98 上的一致说法是「晚 8 点后不需要预约码」**，
  即预约码是**提前预约**（8 点前）才需要的门槛；8 点后放开给学生。官方文档没写这条，但多人独立复述。

## CC98 实测调研结论（2026-11-19，多帖交叉验证）

### 【最重要】「预约码」只在提前预约时卡人，晚 8 点后放开
多人独立复述同一条规则：**前一天晚上 8 点之后，预约次日班次不再需要预约码**。
- 「约明天的话，晚上八点以后不用预约码」（6658599 2楼）
- 「晚上八点以后学生可以预约，一般是老师有预约码，他们会提前约」（6623462 6楼）
- 「八点后可以直接预约」（6623462 4楼）
- 「教师班车也可以约啊，当天晚上8点之后就可以约第二天的了」（6615773 7楼）

官方文档完全没写这条。这解释了「预约码去哪弄」为什么不重要——
**想提前几天约才需要码；当晚 8 点后约第二天，学生直接能约。**

### 司机多数不查预约
- 「我约过几次后面就没约了 因为我做的校车司机都没查过这玩意」（6703075 1楼）
- 「其实不用，一般可以直接上车」（6548031 6楼）
- 「直接上车，其实感觉师傅们都不会看的」（6652998 2楼）
- 「即使显示没票了也一般剩几个座位」（6661241 1楼）

### 预约 vs 不预约的实际上车点差别（6480156 8楼/11楼，讲得最透）
> 「教室班车**非预约只能在最后一站上车，预约的可以在任意站点上车**。其他班车只要是停靠站点都能上。」

- 教师班车在紫金港的最后一站 = **东二门**（从基图过马路，路边有等车区域），官方说的「风雨操场学生开放点」即此处
- 校内始发站：云峰旁边，沿大西区逆时针绕校园，到东二门后出校
- **这是预约的实际价值：换任意站点上车权，不只是换座位**

### 违约机制（系统页面 + CC98 双重确认）
- **累计 3 次违约 → 取消预约资格**（car.zju.edu.cn 页面原文：「违约记录达到3次后,预约资格将被取消!」）
- **什么算违约**：预约了但上车后忘点「确认上车」（最高频踩坑）
- **系统故障也算**：2026-11 系统崩过数次，打不开确认页 → 被强制记违约（6703377、6699486）
- **遇到打不开先点「退票」**，可避免违约；干等会被记违约（6703377 1楼）
- **申诉**：班车预约页最下面三个按钮，最右边那个是申诉；写检讨可清零，实测「第二天就给我清零了」（6661241 2楼、4楼）
- 违约记录按学期清（6311759 3楼）

### 只有 6 个校区，海宁/舟山在别的系统
- car.zju.edu.cn 站点列表：紫金港、玉泉、西溪、华家池、之江、湖滨
- **海宁**：走国际校区微后勤，需「在国际校区申请入驻」，学号不在档案里约不了（6482499 4楼）；
  替代方案：杭海城际，单面约 16 元，时间只比班车慢半小时（6482499 4楼）
- **舟山**：海洋学院班次极少，建议自驾/拼车/长途大巴（6433657 4楼）

### 座位数（CC98 说法，未在接口验证）
「班车一般都是 48 个座位，但预约只有 30 个」——所以预约满了不等于车满了（6527241 4楼）

### 时刻表准不准
- 「发车时间都是准的，至少不会提前发，顶多因为前序晚点而晚发」（6616365 4楼）
- 玉泉→紫金港东二门约 20 分钟出头，但校内停靠站多，到终点约 40 分钟（6616365 6楼）

### 浙大钉班车预约本身很不稳定
2026 年 9–11 月反复出现：打不开、卡登录、进不去、系统崩、强制违约。
搜索「班车预约」得到的 40 帖里，**约一半是报故障的**。
→ 建议：重要行程别只依赖预约，留现场上车后手。
