## 概览
浙大班车（校区间通勤班车 + 紫金港校园观光车「小白车」）的官方数据入口，分三处：

| 用途 | 入口 | 是否要登录 |
|---|---|---|
| 查班次时刻（最实用） | http://www.life.zju.edu.cn/_web/_apps/lightapp/busQuery/mobile/pc/pub/shiftManage.html | **不要** |
| 看公告（临时调整/节假日） | http://www.zwc.zju.edu.cn/hqfwgl/list.htm （总务处 → 后勤服务管理 → 公告通知） | 不要 |
| 学生预约坐教师班车 | 钉钉「浙大钉 → 浙江大学平台 → 搜索『班车预约』」 | 要（钉钉身份） |

另外两个官方说法页：
- 后勤集团「交通服务」：https://zulg.zju.edu.cn/guide/transport.htm（班车/用车/小白车的官方口径）
- 「乘坐班车注意事项」：https://itc.zju.edu.cn/ydxw/2022/0402/c20989a2513531/pagem.htm（谁能坐、凭证要求）

`www.life.zju.edu.cn` 首页本身是苏迪 Coreplus 登录页（账号+Base64 密码+图形验证码），
但**班车查询轻应用挂在 pub 静态路径下、接口免鉴权** —— 不需要登录就能查，这是本页最重要的事实。

## 鉴权
- shuttlebus 只读接口（station / bus / route / busflight 的 `lists.rst`）：**完全免登录**。
- 站点 `/` 的 Coreplus 登录：`POST /login.jsp?domainId=1`，字段 `userName` `password`(Base64) `validateCode` `isSubmitted=1`。
  2026-11-19 实测：拿到同 session 的验证码后单次提交 → 返回「用户名或密码不正确」。
  即**验证码这关过了，但 campus-sso（一卡通）不是这个站的账号体系**，life 站有自己的一套账号。
  未再重试（防锁号）。所以：**别以为「一卡通能登 life」**，也别为了查班次去登录。

## 限流
无 robots.txt（404，Tomcat）。页面 JS 无 RateLimit 头。探索期串行单发（≥2s）未触发 429。
班次数据每天更新一次，正常查询一天几次就够，不要轮询。

## 接口（详见 endpoints.json）
核心四个，全部 `GET`、全部免登录、基址 `/_web/_apps/lightapp`：

| 接口 | 用途 | 关键参数 |
|---|---|---|
| `/shuttlebus/station/api/lists.rst` | 站点表（31 个） | `state=1&page=0&rows=99999` |
| `/shuttlebus/bus/api/lists.rst` | 班车目录（22 辆） | 同上 |
| `/shuttlebus/route/api/lists.rst` | 线路定义（159 条） | 同上（**缺 state/page/rows 会返回 resultCode=-1**） |
| `/shuttlebus/busflight/api/lists.rst` | **班次时刻（核心）** | `id=-1&startStationId=&endStationId=&zj=&startTime=0000&endTime=2359&page=0&rows=99999` |

### busflight 参数语义（不看会踩坑）
- `startTime` / `endTime` 是 **4 位数字字符串**：`705` 表示 07:05，`1737` 表示 17:37。不是 `7:05`。
- `zj` = 运行周期，逗号分隔的星期号：`1,2,3,4,5` 工作日、`6,7` 周末。**周日起算为 7**。
- `id=-1` 表示不限班车；`startStationId=-1`/`endStationId=-1` 表示不限站点。
- `page=0&rows=99999` 可一次取全量（页面自己用 `rows=10`，16 页）。
- 返回字段：`busName` `lineName` `startStationName` `endStationName` `startTime` `endTime` `cycle` `remark`。
  `remark` 里有极重要的限制（"此趟次学生请勿搭乘"、"无课时不运行"、"湖滨只下不上"），**必须逐条读**。

## 坑
1. **首页登录页 ≠ 班车查询入口。** 直接打开 `http://www.life.zju.edu.cn/` 只会看到苏迪登录框，容易误判「要账号」。
   班车查询的真实地址在 `/_web/_apps/lightapp/busQuery/mobile/pc/pub/shiftManage.html`，免登录。
2. **`www.life.zju.edu.cn` 首页标题是「欢迎使用Coreplus核心开发平台！」**，不是「班车查询」——按标题判断站点用途会误判。
3. **route/lists.rst 必须带分页参数。** 只带 `?state=1` 也能过，但完全不带给 `resultCode=-1, result:{total:0}`（看着像「没数据」，其实是参数没给全）。
4. **busflight 的 time 字段是整数串**，格式化时 `String(t).padStart(4,'0')` 再切片，否则 `705` 会显示成 `7:5`。
5. **时刻数据是「当前学期正在运行的班次」，公告优先级更高。** 2026-11-18 总务处公告已把教师8号（紫→之）17:10 改为 21:25、把 22:05 改为 22:10，
   而 busflight 接口里 `22:05` 仍在（`cycle` 含 6,7 的教师10号）。**查完接口要对照总务处公告**，接口不是唯一真源。
6. **班车分身份**：教师班车 / 研究生班车 / 学生教学专用班车是不同权限，不是「有车就能上」。见下节。
7. PDF 时刻表链接在班车查询页页头（`zjgbc1110.pdf` 完整版、`bcskjb1110.pdf` 简表、`dtjbc.pdf` 短驳、`images/sqbcsk.pdf` 暑期版）。
   简表 PDF 的文本层可直接用 pdf.js 提取（实测 9766 字符），短驳 PDF 是扫描图，文本层只有 275 字符。
8. `lightapp.zju.edu.cn` 是另一个苏迪实例，CAS 登录后会立刻「请重新登录」，别在那儿绕。

## 乘坐规则（官方原文要点，2026-11-19 抓自 itc + zulg）

### 谁能坐哪辆车
- **教师班车**：按教职员工上下班/上课乘坐量调度，**其他人员未经许可不得乘坐**。
  教职员工凭工作证或校园卡乘坐。
- **研究生班车**：凭研究生证乘坐。
- **学生教学专用班车**：凭本科生院教务处 / 研究生院培养处 / 总务处发放的乘车证（券）乘坐，且要随带学生证备查。
- **学生搭教师班车的唯一合法窗口**：教师班车在各校区**最后一个站点**（紫金港是风雨操场站点的「学生开放点」），
  在司机给中间站点老师/上课学生预留座位后**仍有空座**时，凭学生证可以上车。不是「想坐就坐」。

### 「预约码」到底是什么 / 怎么拿（2026-11-19 追加核查）

**官方只写「院系下发的预约码」，没有公开的申领页面、没有申请表单、没有专门通知。**
以下按证据强度分层，不把推断当事实。

**【原文·确证】zulg 交通服务页（https://zulg.zju.edu.cn/guide/transport.htm）**
> 「本科生通过**院系下发的预约码**，可在『学生乘坐班车预约系统』预约乘坐教师班车；
> 未预约的学生可在校区内最后一站，在司机给中间站点的老师或上课学生预留若干座位后仍有空座的情况下搭乘班车。
> 预约流程：登录钉钉『浙大钉→浙江大学平台→搜索班车预约』，预约成功后持有效**乘车码**乘坐对应的教师班车。」

**【原文·确证】时刻简表 PDF（bcskjb1110.pdf）注意事项第 2 条**
> 「乘客一律凭证（**码**）乘坐班车，工作人员将进行查验……教职员工凭工作证、校园卡乘坐教师班车；
> **学生凭预约码、助教证乘坐**，并随带本人学生证、研究生证或校园卡备查。」

**【原文·确证】同 PDF 第 5 条与末尾**
> 「**学生乘车券**是专门解决学生上必选课、辅修课等的部分交通问题而发放的，仅限上课时使用，不上课时请勿搭乘。」
> 「另外我们已发现假的**预约码**，如若查获伪造或使用假预约码者，将移交学校相关部门作严肃处理。」

**【关键证据链：预约码 = 学生乘车券的数字化】**
同一段「谁能坐」的表述，两代官方文本逐字对应：
- 2020/2022 版（itc 转载）：「学生凭**本科生院教务处、研究生院培养处或总务处发放的乘车证（券）**、助教证乘坐」
- 2026 版（时刻简表 PDF）：「学生凭**预约码**、助教证乘坐」

同一句、同一位置，「券」换成了「码」。**所以发放主体大概率延续为：本科生院教务处 / 研究生院培养处 / 总务处，
再经院系（学院教务科 / 学工办）下发到学生。** 这是推断，不是官方明文。

**【重要区分：预约码 ≠ 乘车码】**
- **预约码**：院系下发的**资格凭证**，作用是在钉钉「班车预约」里下得动单。
- **乘车码**：预约成功后系统生成的**当次车票**，上车出示给司机查验。
原文「本科生通过院系下发的预约码，可在……预约……；预约成功后持有效乘车码乘坐」把两者分得很清。

**【已排除的路径】2026-11-19 逐一实测**
| 渠道 | 结果 |
|---|---|
| 「我的浙大」应用中心全量 62 个应用 | 班车类**只有「班车查询」**，无「班车预约」（loadServiceApps.rst 实测） |
| life.zju.edu.cn 轻应用命名枚举（busBook/busBooking/busOrder/busReserve/busAppointment/shuttlebus 等 12 个） | 全 404，**无 web 端预约入口** |
| 总务处公告栏 5 页共 46 篇班车类通知全文 | 出现「预约」仅 2 篇，且都是**校园巴士电话预约**（88206142），与教师班车预约码无关 |
| 教务网 zdbk 575 条通知（翻 3 页） | 班车相关 0 条 |
| 学工部 xgb / 三全育人 eta / 本科生院 ugrs / 校网 | 「预约码」0 次 |

**结论：预约码不走 web，只在钉钉端 + 院系线下发放。** 要拿到只能走两条路：
① 找院系教务科 / 学工办要；② 打总务处 88208698 或本科生院 88208639 问当期发放口径。

**【另一条被忽略的合法凭证：助教证】**
原文「学生凭预约码、**助教证**乘坐」——**持助教证的学生可以坐教师班车，不需要预约码**。
这是绕开预约的官方通道，但仅限助教身份。

**【2026 版时刻表新增的硬限制】**
多条趟次 remark 明写「**此趟次学生请勿搭乘**」（如紫金港→玉泉 11:45 / 17:37 教师14号、紫金港→华家池 17:37 教师6号），
即使有预约码也**不得**乘坐这些趟次。查班次时必须逐条读 remark。

### 本科生怎么「预约」坐教师班车
> 「本科生通过院系下发的**预约码**，可在『学生乘坐班车预约系统』预约乘坐教师班车；
> 预约流程：登录钉钉『**浙大钉 → 浙江大学平台 → 搜索班车预约**』，预约成功后持有效**乘车码**乘坐对应的教师班车。」

即：① 先拿到院系下发的预约码 → ② 钉钉里搜「班车预约」下单 → ③ 上车出示乘车码。
（预约是写操作，本 YONKIK 探索不执行；入口在钉钉客户端内，不在 web。）

### 其他硬规则
- 禁止携带危险品/异味物品/活禽宠物；大件物品超 60×80cm 不带入车厢；车厢内不饮食。
- **机动车禁止超载，班车不能站人**。超载时请改乘其他交通方式。
- 7、8 号班车的上课专车，是**开课前 2 天**在校网「班车时刻表」更新，不另行张贴。
- 班车运行随实际动态调整，**乘坐前查办公网「班车信息」/总务处公告**。
- 已发现伪造乘车证（券），查获移交处理。

## 校园观光车（小白车 / 紫金港内循环）
- 紫金港校区内「小白车」，路线基本覆盖全校，约 **15 分钟一班**。
- 收费：**1 元/人次**，微信/支付宝/校园卡/云闪付均可。
- 实时位置/线路/时刻：微信公众号「浙大后勤」→ 快捷入口 → 班车查询 → 小白车（或 服务中心 → 小白车查询）。
- 循环线路（时刻表 remark 里的官方描述）：
  `7:50 8:15 8:30 东大门→风雨操场→教学区→生科院→医药组团→化学楼→西教学区→生活区→校区医院`

## 班次规模（2026-11-19 实测）
- 全周班次 **165** 条；仅工作日（zj=1..5）**155** 条；周末（6,7）约 10 条。
- 站点 31 个、线路定义 159 条、班车 22 辆（教师1-16号、教师校区间1-3号、研究生1-2号、学生教学专用1号）。
- 主要方向班次数（工作日）：玉泉↔紫金港各 24 班；华家池↔紫金港各 13 班；西溪↔紫金港 14/13 班；
  紫金港↔玉泉(4舍南侧) 9/7 班；紫金港↔之江 5/5 班；西溪↔之江 4/4 班；湖滨方向 2-7 班。

## 脚本用法
```
node sites/www.life.zju.edu.cn/crawler.mjs --list
node sites/www.life.zju.edu.cn/crawler.mjs stations
node sites/www.life.zju.edu.cn/crawler.mjs buses
node sites/www.life.zju.edu.cn/crawler.mjs routes
node sites/www.life.zju.edu.cn/crawler.mjs shifts --from 紫金港校区 --to 玉泉校区则通楼北侧 --weekday 1
node sites/www.life.zju.edu.cn/crawler.mjs shifts --days 1,2,3,4,5,6,7 --from 玉泉 --to 紫金港
node sites/www.life.zju.edu.cn/crawler.mjs pdfs --outDir ./out
```
`--from` / `--to` 支持站点名模糊匹配（`玉泉` 会命中第一个含「玉泉」的站点，多个玉泉站点请写全名）。
