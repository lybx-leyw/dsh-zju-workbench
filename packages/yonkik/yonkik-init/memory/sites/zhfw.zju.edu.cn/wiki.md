## 概览（它到底是什么）

`zhfw.zju.edu.cn` 是 **Webplus CMS 内容管理系统**搭的**新闻/公告/校情门户**，标题「综合服务网」，
侧栏导航是「校情总览 / 信息公开 / 求是新闻 / 综合服务 / 学校机构 / 教师队伍 / 教育教学 / 科学研究 / 招生就业 / 合作交流 / 走进浙大」。

首页 73KB，是**栏目聚合页**：热点专题、资讯信息、最新文件、公示公告、重点提示、即时更新。
所有内容服务端渲染、全部公开。

历史（站内「关于本站」自述，原文照录）：
> ZUPO 是由校长办公室提出并与学校网络应用开发室合作，于 1996 年 10 月正式推出测试版试运行，
> 原本为校长办公室主页，其域名 ZUPO 为 Zhejiang University President Office 的缩写，
> 后发展为行政办公网，**2014 年 8 月 18 日更名为「综合服务网」**。

## 判定：不是办事入口

**这是本组最容易误判的一站，明确下结论：zhfw 不能办事，它只是「通知你在哪办事」的那张网。**

| 判据 | 实测证据（2026-11-20） |
|---|---|
| 站点骨架是 Webplus CMS | 全部 URL 为 `/<栏目>/list.htm` + `/YYYY/MMDD/c<数字>a<id>/page.htm`，典型 Webplus 文章路由 |
| 首页没有办事表单 | 73KB 全是栏目列表 + 文章链接；页面上的「账号/密码」是**浙大通行证登录弹窗**，登录后也只是个人化栏目 |
| **「办事中心」导航指向别处** | `https://service.zju.edu.cn/_web/customized/bsdt.jsp?_p=...` 与 `https://service.zju.edu.cn` —— **办事能力在 service** |
| 内容性质是公告 | 停电通知、班车调整、任职公示、成果转化公示、招聘启事、申报通知 |

**所以：**
- 学生说的「去综合服务网办事」实际是「去综合服务网**看通知**，然后**跳到 service 办事**」。
- 对 `zhfw` 的正确用法 = **公告检索源**（尤其「即时更新」「重点提示」栏目，能拿到班车调整、停电、假期安排这类时效信息）。
- 对「办事流程怎么办」的价值 = 0；那部分去 `service.zju.edu.cn`（见该站 wiki）。

## 鉴权

**全站免登录。** 没有 CAS 跳转、没有 401/403。页面右上角的登录弹窗只服务于个人化栏目，不影响任何内容页。

## 限流

- `robots.txt` → 标准 nginx 404（196B）。
- 无 `X-RateLimit-*` / `Retry-After`。
- 保守默认：**串行、间隔 ≥2s、并发 1**。本次未触发 429。

## 接口（详见 endpoints.json）

三条，全是 HTML（无 JSON API）：

| 接口 | 用途 | 关键点 |
|---|---|---|
| `GET /` | 首页栏目聚合 | 73KB |
| `GET /<栏目>/list.htm`，翻页 `list<N>.htm` | 栏目列表 | 每页 24 条，`all_count` 给总数 |
| `GET /YYYY/MMDD/c<栏目>a<id>/page.htm` | 文章正文 | 服务端渲染 |

列表条目正则：
```
<li><a href='(/\d{4}/\d{4}/c\d+a\d+/page\.htm)' target='_blank' title='([^']*)'>[^<]*</a> (\d{4}-\d{2}-\d{2})</li>
```

## 坑

1. **【最重要】别把 zhfw 当办事入口。** 它的「办事中心」是跳转到 `service.zju.edu.cn`。这是 CC98 口径与实测最容易冲突的地方——CC98 上「去综合服务网办」的说法，落到 URL 上其实都是 service。
2. **数字栏目 ID 不能当列表路径。** `/4903/list.htm` 返回「htm file not found ,redirecting...」（301 到 404）。数字 ID 只出现在**文章 URL** 的 `c<数字>` 段；**列表页必须用语义化别名** `zhfw_*`。
3. **本机网络陷阱：浏览器打不开 ≠ 站点挂了。** 用 `https://` 直连（node:https）稳定 200（73KB）；但 **headless Chromium 访问 `/11946/list.htm` 会被 302 到 `https://webvpn.zju.edu.cn/login`**，triage 首轮也观察到过 `/` 跳 WebVPN。这是**本机代理/网络侧的路由问题**（详见 `~/.yonkik/sites/_playbook.md` 的「本机代理 7993 的脾气」），不是站点鉴权。判定站点可达性要用直连 HTTPS，不要用浏览器结论。
4. **带完整 Chrome 头反而可能被回空壳。** 实测带 `accept-encoding: gzip, deflate, br` + `sec-ch-ua` + `upgrade-insecure-requests` 时，返回 **9,610B 无 title 的空页**；同 URL 带 `accept: */*` 或 `text/html` 则 69,272B 正常。抓取时**别把浏览器头全抄**，最小化头更稳。
5. **列表分页是 `list<N>.htm` 不是 `list.htm?page=N`。** query 参数无效。
6. **`/4901/list.htm`（节假日通知所在栏目）301 到 404**，但**文章本身可读**（`/2025/0616/c5072a3061710/page.psp` 实测 200，标题「浙江大学印发《浙江大学2025-2026学年校历》的通知」）。即：文章层可达、列表层栏目别名不全。要按文章 URL 直取时用 `page.psp` 或 `page.htm` 都行。
7. 首页文字里有大量重复导航（同一批栏目在多个 `<ul>` 里重复），**解析首页要去重**，直接抓正文容易把导航当内容。

## 站内搜索实际指向 s.zju.edu.cn（2026-11-22）

- 综合服务网页面里的搜索框 `form[action="https://s.zju.edu.cn/search/all.do"]`，提交时拼 `?words=<关键词>` 并 `window.open`。
- 试过 `/_web/search/main.psp`（HTTP 200、HTTPS 超时）与 `/_web/search/searchInfo.jsp`（403）：前者只有那个跳转表单，**本站没有独立搜索后端**。
- 所以「站内搜索」这一项应去 `s.zju.edu.cn` 找，不在本站。
