# 学校订购电子图书（双源检索）

> **状态：blocked**（2026-11-22）｜原因：两源都按**校园网出口 IP / 机构 SSO** 认证，本机出口在墙外。

**本页索引**：两源是什么 · 查询协议（可直接抄） · 为什么本机拿不到 · 合规边界 · 怎么打通

---

## 两源是什么

学校买的电子书散在多个平台（文泉学堂、科学文库、书递、各外文平台），要查「有没有某本书的电子版」
需要两个源一起查——单查任一个都会漏。

| 源 | 覆盖 | 匹配能力 |
|---|---|---|
| **Serials Solutions 360 导航** | 图书馆主页「电子图书」入口，聚合上述全部平台 | ISBN / 标题开头 / 标题等于 |
| **超星电子书（汇雅）** | `www.sslibrary.com`，导航里没有它，要单独查 | **书名包含匹配** |

**两源互补的关键点**：导航对中文只能按「开头匹配」（因为「包含所有词」会超时，见下），
而超星是包含匹配 —— 搜「数据结构」时导航漏掉的「大话数据结构」只有超星能捞到。

## 查询协议（可直接抄用）

### Serials Solutions 360

```
GET https://gk4pb6yy8y.search.serialssolutions.com/
    ?V=1.0
    &N=20                     每页条数
    &tab=BOOKS                书目（另有 JOURNALS）
    &L=GK4PB6YY8Y             浙大的 libraryId
    &S=<匹配方式>
    &C=<关键词>

翻页：&sortby=SB_T&B=<起始偏移>
```

匹配方式 `S` 的取值：

| 值 | 含义 | 中文能用吗 |
|---|---|---|
| `A_T_B` | 标题开头为 | ✅ **中文用这个** |
| `A_T_M` | 标题等于 | ✅ |
| `T_W_A` | 标题包含所有词 | ❌ **含汉字会 35 秒超时** |
| `I_M` | ISBN 等于 | ✅（带不带连字符都行） |

> 「中文只能用开头匹配」这条是 `dsh-zju-campus` 在 2026-10-07 实测的：四个不同的中文词用 `T_W_A`
> 全部 35 秒无响应。同样，**每页 100 条要 10 秒以上，20 条约 2.7 秒**——所以一页取 20，别贪多。

结果页结构（要做解析就照这个）：

```
每条   div.SS_Holding
  书名     .SS_JournalTitle > strong
  ISBN     .SS_BookISBN
  版本     .SS_Edition
  作者     .SS_Authors
  出版社   .SS_Publisher
  日期     .SS_Date
  平台名+直达  a.SS_JournalHyperLink（文字=平台名，地址=/log?…&U=<平台上的地址>）
总数     .SS_ResultsCount
```

### 超星电子书

```
GET https://www.sslibrary.com/book/search/do
    ?sw=<词>
    &field=<1书名 | 2作者 | 6目录 | all全文>
    &page=1
    &pagesize=<n>
→ JSON { success, data: { result, total, maxpage } }
```

书页：`/book/card?cnFenlei=…&ssid=…&d=<bookCardD>&isFromBW=…&websiteId=…`
（**只带 `ssid` 会报 500**，其余参数必须齐）。

## 为什么本机拿不到（实测）

两个源都是「**按出口 IP 认机构**」——学校的订阅按 IP 段授权，不在校园网出口就一律跳登录页：

```
SS360  → 302 https://login.serialssolutions.com/sso/login?ClientID=GK4PB6YY8Y&TARGET=…
超星   → 302 https://www.sslibrary.com/entry/login
```

本机经代理出口在墙外，所以直接掉登录页。**这不是站点挂了，是鉴权前提不满足。**

对照：`zju.summon.serialssolutions.com`（同一家的 Summon 发现系统）本机 **200 可用**——
说明**Summon 对浙大是 IP 白名单放行、360 导航不是**。要做文献检索，Summon 可直连，360 导航不行。

## 合规边界（重要）

按《浙江大学图书馆电子资源使用管理办法（试行）》：

- 第三条允许：个人使用/研究目的的**检索、浏览**、少量存档、简短引用
- **第四条禁止**：用自动下载工具批量下载、连续系统集中批量检索、整库下载
- **后果**：不是封个人号，是「部分 IP 访问中断，甚至整个电子资源访问被终止」

**落到本库的口径**：这两个源**只做检索元数据**（有没有这本书、在哪个平台、直达链接），
**绝不批量下载全文**。`grep` 到 PDF 下载地址也不去拨它。

   ```
   enc = hex("wrdvpnisthebest!") + hex(AES-128-CFB(host, key=iv="wrdvpnisthebest!"))
   ```
3. 经隧道请求上表的查询 URL，解析规则照抄本页结构

# 电子书：只告诉路径，不做任何自动获取

**本文件是本资产的执行口径，优先于其它一切说明。**

## 一句话

电子书这条线**不做任何自动化**。用户需要电子书时，告诉他下面这些**官方入口**，让他自己点。

## 为什么不自动化

1. **入口已确认是图书馆官方路径**（2026-11-22 实测 `libweb.zju.edu.cn` 200 / 92,431B）：

   ```
   图书馆主页「电子图书」→ http://gk4pb6yy8y.search.serialssolutions.com/?L=GK4PB6YY8Y&tab=BOOKS
   图书馆主页「数据库导航」→ https://libdb.zju.edu.cn/s/lib/libtb/
   ```

   不是我们自己找的野平台，走的是正门。

2. **《浙江大学图书馆电子资源使用管理办法（试行）》第四条**明令禁止：
   自动下载工具/机器人下载、连续系统集中批量检索或下载、整刊整库下载、破解。

3. **后果不是封个人**，是「部分 IP 访问中断，甚至整个电子资源访问终止」。
   学校按 IP 段买的年费，一个人滥用全校受影响。

4. **即使只想拿元数据**，写脚本高频循环打检索接口也落在「系统化集中检索」范围内。
   所以本库对电子书**一律不写自动检索脚本** —— 不是能力问题，是这条线不该自动化。

## 用户要电子书时，怎么答

直接给路径，不代查、不代下：

| 需求 | 告诉用户去哪 |
|---|---|
| 查某本书有没有电子版 | 图书馆主页 → **电子图书**（Serials Solutions 360），或 **Summon** 发现系统 |
| 找某个数据库 | 图书馆主页 → **数据库导航**（`libdb.zju.edu.cn/s/lib/libtb/`） |
| 单本中文电子书 | 图书馆采购的中文平台（超星汇雅等），从图书馆主页进 |
| 文献/论文检索 | **Summon**：`https://zju.summon.serialssolutions.com/`（本机实测 200 可用） |
| 校外访问 | 图书馆主页有「校外访问」说明；或走 WebVPN 通道（需上网账号） |

**注意**：`Summon` 本机可直接访问；360 导航与超星按校园网出口 IP 认证，校外需 WebVPN。

## 双源实测：汇雅书目检索可用、Summon 走 SSO（2026-11-22）

### 超星汇雅 `www.sslibrary.com`

- `GET https://www.sslibrary.com/book/search/do?sw=<关键词>` → **200，免凭据**，返回**真实结构化书目**。
- **坑**：响应是**双重 JSON**——body 本身是一个 JSON 字符串，要 `JSON.parse` 两次。第一次 parse 得到字符串，第二次才是对象。
- 结构：`{success, data:{result:[10条/页], total, maxpage}}`。搜「高等数学」得 **8543 条 / maxpage 100**。
- 字段很全：`bookName`、`author`、`isbn`、`cnFenlei`（中图分类号）、`publisher`、`page`、`coverurl`、`mulu`（目录）、`ssid`、`dxid` 等。
- 抽样 5 条均为 `isBlock:true`、`isauthorized:true`，说明落在机构授权范围内。

**这条与上游清单的判断不同**：清单说「未验证成功业务结果」，实际**书目检索是通的**。

### Summon SS360 `gk4pb6yy8y.search.serialssolutions.com`

- `/` → **302 到 `login.serialssolutions.com/sso/login`**，需机构 SSO，无凭据不可读。与清单一致。

### 边界（重要）

- 拿到书目 ≠ 可以拿全文。`isBlock` / `isauthorized` 控制的是正文可达性。
- `maxpage=100` 表明单次查询上限 100 页，**逐页枚举仍属批量取数**，不做。
- 本库只记录「书目检索可用」这一事实与接口契约，不做全文抓取、不下载、不批量翻页。
