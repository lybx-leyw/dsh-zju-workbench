# dsh-zhiyun-core-handout

讲义导出到笔记库：**把当前讲义写成笔记库里的 `.md`，一份，单向，不覆盖**。

零 IO —— 文件读写全部经注入的笔记服务，包内没有一行 `node:fs`。

## 这个包只做一件事

学习页上有一个「导出到笔记库」的按钮。点了，就把**当前讲义**
（知识记录里的 `record.lecture`）编码成 Markdown，写进笔记库
`<课程>/<节次>.md`。

导出的那一份是**用户的东西**：可以在任意编辑器里改、可以改名、可以删。
本包不会回读它，也不会拿它去影响任何既有行为。

## 三条刻意的边界

### 1. 单向：只写不读

`record.lecture` 是**唯一真源**。学习页讲义渲染、讲义检索（两层）、出题、
知识点导航，全部继续读它。笔记库里的 md 只是导出物。

> 早先的设计是想让 md 成为真源（用户改 md、学习页跟着变），代价是要改掉
> 上面那四处读取路径 —— 跨四个包的深度挂钩。那个方案已放弃。

### 2. 不覆盖：重名加「（2）」后缀

每次导出都**新写一份**。已经有同名笔记时依次尝试 `<节次>（2）`、`（3）`……
由用户在笔记库里自己决定留哪个。

理由：导出是附加动作，用户很可能在上次导出的那份上手写了很久。
再导一次就拿新内容盖掉它，等于删掉他的工作 —— 而点「导出」时他期待的是
「再拿一份」，不是「覆盖上次那份」。

上限 1000 份，到顶给一个明确的错误，而不是继续往后加序号。

### 3. 不参与生成

讲义生成完**不会**自动导出。一次生成就往用户笔记库里塞一份文件，
而他可能根本不想导，那是噪音。导出只在用户按一下时发生。

## 没有版本对、没有归档、没有回退

早期版本把「版本 =（AI 基线, 讲义 md）」做成本包的核心，还有
`讲义归档/v<N>/`、swap、基线读写。**那些全部移除**，原因：

- 那套设计的目的之一是「回退讲义」，而回退的是**笔记库里的副本**；
- 副本的历史与回退，用户在笔记库里自己就能做；
- 维持那套机制需要 `readRaw`/`writeRaw`、归档目录排除索引、版本号分配、
  先读后写的交换计划 —— 一整套只为一个已被判定为不需要的功能服务的复杂度。

**代价是明确的**：导出之后回退笔记库里的副本，**学习页看到的讲义不会变**。
学习页继续显示 `record.lecture`，那是「AI 生成的最新一份」。

## md 的形状：只有内容，没有机器字段

```markdown
# 数据结构 第三讲

## 第一章 绪论

### 1.1 什么是算法

#### 讲解

算法是求解问题的有限步骤。

#### 定义 · 算法的五个特性

有穷性、确定性、可行性、输入、输出。

#### 例题 · 二分查找

给定有序数组，求目标下标。

##### 解答

O(log n)，每次折半。
```

- `##` 章、`###` 知识点、`#### 类型 · 小标题` 块。
- 块类型只有五种，与 `dsh-zhiyun-page-study/src/lecture-content.jsx` 的 `kinds` 一致：
  讲解 / 定义 / 步骤 / 例题 / 说明。
- **例题**用一行 `##### 解答` 分隔题干与解答（其余四种块只有一段正文）。
- 页码、时间锚点、`blockIndexes` **不写进 md**：那些是机器字段，
  留给 `record.lecture` 自己带着。

## 错误态度

认不出的块类型**不抛错**，降级成「讲解」并留 warning，正文一个字不丢 ——
md 可能已经被人改过，为一个排版失误让整份讲义读不出来，是拿用户的正文去惩罚它。

空讲义**拒绝导出**（`NO_CHAPTERS`）：往笔记库里写一个空文件，
比什么都不写更糟 —— 用户会以为「这一节的讲义就是这样」，而实际是生成没产出内容。

## 服务面

```js
ctx.zhiyunHandout.exportLecture({ courseTitle, lessonTitle, chapters, title })
// → { path, name, folder, deduped, chars }

ctx.zhiyunHandout.exportMarkdown({ courseTitle, lessonTitle, markdown })
// → 同上；给「讲义已经编码好了」的场合用，省一次编码

ctx.zhiyunHandout.ready()   // 诊断：笔记库挂上了没有
```

`zhiyunVaultNotes` 是**惰性**取的，不写进 `inject`：它缺席时导出只是不可用，
不该把学习页整片拖成 pending。
