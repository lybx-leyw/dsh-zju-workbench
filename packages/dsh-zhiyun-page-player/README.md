# dsh-zhiyun-page-player

「看课」页：一节回放的**视频 + 课件 + 字幕**同屏。

## 为什么这一页存在

本仓原先把「看回放」降级成「我的课」里一个 `target="_blank"` 外链 —— 点开跳浏览器，
课件与字幕留在工作台里，两边再也对不上。原始设计里这是一个**独立页面**
（`player_page.dart`，1260 行），视频是主角，课件与字幕是它的两个跟随面。

现在按原始设计的形状补上：**「我的课」展开节次 → 点某一节「看课」→ 进这一页**。

## 这一页不在侧栏

`NAV` 里它标了 `sidebar: false`，所以：

- **不列在主导航** —— 它从「我的课」进来，没有课程上下文时点进去只能看到空态；
- **不进 Ctrl+K** —— 搜出来一条「看课」同样点不出东西；
- 但**仍在 `NAV` 里** —— 外壳的面板、插槽、`navigate()`、`activePage()` 全部以 `NAV`
  为唯一真源（`navigate()` 对不在 `NAV` 的 id 直接抛错）。另建一套路由就要在这四处
  各加一条分支，那才是重复。

## 三条不能破的约定（照原始设计）

1. **播放器常驻**：`<video>` 在任何布局下都挂在树里。卸载它 = 声音当场断，
   所以页签切换不改视频节点 —— 本页用 CSS 控制显隐，不用条件渲染。
2. **时间轴是唯一真源**：当前时刻由 `<video>` 的 `timeupdate` 驱动，课件页与字幕行
   都是它的**投影**。反过来（让课件驱动视频）会与用户拖动进度条打架。
3. **点字幕才跳**：不自动滚动。用户可能正在读某一行，自动滚走是打断。

## 两个容易写错的地方

**「当前在讲哪一句」取的是最后一条起点不晚于当前时刻的**，不是时间上最近的一条。

```
跳到 10:00 时，要看到 10:00 时**正在讲**的那一句，
而不是离得最近的那句（可能是 10:05 的下一句）—— 差一个语义，字幕会看起来总是领先一句。
```

找不到（时刻早于第一条）时给 `-1`，页面据此显示「还没开始」，而不是硬套第 0 条。

**手动翻课件会「钉住」页码**：翻页时同时 `jumpTo` 该页的时间点，并置 `pinned`；
点字幕或换节则放开。不这样做的话，用户翻到第 30 页、视频还在第 3 页的时间上，
下一帧 `timeupdate` 就把他弹回第 3 页 —— 翻页看起来"没反应"。

## 与「学习」页的分工

| | 「学习」页 | 本页 |
| --- | --- | --- |
| 做什么 | **整理与复习**：讲义、终稿、出题、笔记 | **回到课堂**：哪一段在讲什么、对着课件看 |
| 读什么 | 解析产物（`result` / `lecture` / `quiz` / `note`） | 原始素材（`content.slides` / `content.subtitles`） |

两者读同一份 `state.content`，但角度不同：这一页不整理、不出题，只把原始素材按时间对齐。

## 边界

- `inject: ['slots']`，领域状态用 `ctx.inject(['zhiyunStudyController'], …)` 惰性取
  （来自 `dsh-zhiyun-study-core`）：停用状态包时这一页只是空着，不会把整个前端拖成 pending。
- 注册插槽带 `priority: 10` —— 外部扩展用默认 0 就能遮蔽这一页。
- 没有选节时显示「去我的课」而不是空白 —— 直接开这一页是可能的（比如从快捷方式进来）。
- **站内播放用浏览器原生 `<video>`**，不引入第三方播放器：智云回放是完整 MP4 直链
  （实测形如 `..._1920_1080.mp4`，约 1.26 GB），不是 HLS，原生控件够用。

## 尚未做

- **拖进度条时同步课件/字幕**：`timeupdate` 已经驱动了两者，拖动也会触发 `seeked`
  （已监听），但**悬停进度条浮出该时刻的 PPT 缩略图**没做 —— 那需要自定义进度条控件。
- 进度条上叠「内容分段 + 语速热力」两条数据：数据层已在 `dsh-zhiyun-player` 里备好
  （`toSeekBar()`），但没有绘制层；自定义进度条时接上。

## 插槽

在 `zhiyun.player.content` 注册内容（`children` 声明归外壳）。

## 验证

页面本身没有单测（客户端包在本仓靠真实宿主验证）。相关守卫：

```bash
node --test tests/plugins-page.test.mjs   # 接线：NAV / build / profile 三处必须齐
node --test tests/profile.test.mjs        # NAV 语义：子页不上侧栏但仍能被 activePage 认出
npm run check:css                         # 本页样式与其他包无顺序依赖
```
