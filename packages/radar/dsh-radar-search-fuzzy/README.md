## 实测差分（同一语料、同一 `findIn` 语义）

复现方式：`node` 里 `import` `fuse.js@7.5.0/dist/fuse.basic.min.mjs`，对 8 条课程语料
（`离散时间傅里叶变换的收敛条件` / `大数定律与中心极限定理` / `傅里叶变换在信号处理中的应用` /
`矩阵的秩与线性方程组的解` / `拉格朗日中值定理` / `梯度下降法的步长选择` /
`The Fourier Transform and its Applications` / `马尔可夫链的平稳分布`）逐条检索。
「合并」= 字面命中 ∪ Fuse 命中（`threshold = 0.4`，分层扫描见 `SCAN`）。

| 查询 | 现状字面 | 严格档（mm=2） | 合并后 | 说明 |
| --- | --- | --- | --- | --- |
| `傅里叶` | 2 | 2 | 2 | 完全一致 —— **零回归** |
| `付里叶`（同音字错） | **0** | 2 | **2** | 现状整条静默消失 |
| `傅利叶`（中间字错） | **0** | 0 | **2**（放宽档） | 只有 `minMatchCharLength=1` 能救回 |
| `中植定理`（音近错） | **0** | 1 | **1** | |
| `大数定率` | **0** | 1 | **1** | |
| `离散傅里叶`（漏字） | **0** | 2 | **2** | 严格档即可 |
| `fourier` | 1 | 1 | 1 | 英文零回归 |
| `中值定理` | 1 | 1 | 1 | 零回归 |
| `梯度下降学习率`（多字） | 0 | 0 | 0 | **救不回来**（`score ≈ 0.43`） |
| `量子力学` / `考试` / `作业` / `食堂` / `篮球` / `水卡` | 0 | 0 | 0 | 无关词不召噪声 ✅ |

**结论**：在 10 条查询上，合并后的命中集合 **严格 ⊇ 现状**（R1 成立），且 6 条无关词全部 0 命中。

## 已在实测中踩到的三个坑（写进 `src/upstream.js` 的 TODO）

| # | 现象 | 影响 |
| --- | --- | --- |
| **R1** | 近似匹配只该「多出来」，不该「少下去」 | 实现时**不能删掉**字面 `indexOf`，只能当前置快路径 |
| **R2** | 固定 `minMatchCharLength=1` → 单字查询 `的` 在 8 条语料里命中 **5** 条（噪声）；固定 `=2` → `傅利叶` **0** 命中 | 必须**分层扫描**（严格档 → 落空才放宽），一个固定值同时满足不了两半 |
| **R3** | 多文档同一实例下 `matches` 可能为 `undefined`，单文档实例下稳定返回 | `toLocalSpan()` **必须**容忍 `indices` 缺失，否则高亮会整片 `undefined` |

另有两条**版本事实**必须写进实现：

- `7.5.0` 的 npm 包**没有** `dist/fuse.min.js` / `dist/fuse.basic.min.js`（unpkg 实测 404），
  只有 `dist/fuse.mjs`、`dist/fuse.basic.min.mjs` 等少数出口。照旧文档写 `fuse.min.js` 会直接装不起来。
- **只能用 basic 构建**：完整构建带 extended search（`^` 前缀 / `!` 否定 / `'` 精确 / `|` 或），
  那是**新的查询语法**，会改变用户输入的含义 —— 属于「改档位」，本包不允许。
  若 `exports` 挡死了 `dist/*` 子路径，则须退回「默认入口 + 输入含扩展语法字符时走纯字面」，
  这一条**必须人工拍板**（`src/upstream.js` TODO-A）。

## 边界（不能在实现时顺手越过）

- **不改 `QueryMode` 语义**：`titleOnly` / `tagFilter` 的规则由档位决定。
- **不引入排序**：Fuse 的 `score` 一律丢弃。加排序是 `dsh-radar-search-rank`（minisearch）那条轴。
- **不做简繁 / 拼音**：那是 `dsh-radar-pinyin-match` 那条轴。
- **不切词**：那是 `dsh-radar-search-segment`（jieba-wasm）那条轴。
- **不碰写路径**（`renameLinks` / `resolve`），只碰 `findIn` 一处读路径。

## 与同族骨架的边界（避免「同一处换两次底层」）

本仓 `packages/` 下已有三个同样瞄准 `layered-search.js` 的骨架：

| 骨架 | 换掉的是什么 | 回答的问题 |
| --- | --- | --- |
| `dsh-radar-search-rank`（minisearch） | **排序**层 | 哪条更贴？ |
| `dsh-radar-search-segment`（jieba-wasm） | **切词** | 词和词之间断在哪？ |
| `dsh-radar-pinyin-match` | **读法**（读音） | 只记得怎么念怎么办？ |
| **本包**（fuse.js） | **判据**（容错） | 打错了一个字还算不算？ |

四者在实现上**互斥于同一行代码**（都改 `findIn`）。**建议评审时合并裁决**：若只准进一个，
优先 `pinyin-match`（中文课「只记得读音」更常见）；若允许多个，`pinyin-match` 与 `fuse.js`
可以合成「字面 → 拼音 → 近似」三级链，但**必须**先定义清楚每一级的失败边界，
否则会出现「拼音把字拆错、Fuse 又把错字配回去」的**双重猜测**，用户无法判断结果可信度。

## 验收标准（评审通过后实现时按此写测试）

1. **命中集合 ⊇ 旧实现**：对现有 `tests/study.test.mjs` 里全部检索用例，新实现的结果集
   必须包含旧实现的每一条（逐 `id` 比对）。
2. **无关词零命中**：`量子力学` / `食堂` 之类在测试语料上仍为 0（防噪声）。
3. **单字查询不炸**：`findIn` 对单字查询的返回值与旧实现**完全一致**（分层扫描的严格档
   对单字自然落空 → 合并后等于字面结果）。
4. **区间形状**：`matchEnd` 为开区间（`[4,10]` → `matchEnd = 11`），`previewOf()` 的预览
   不多字不少字。
