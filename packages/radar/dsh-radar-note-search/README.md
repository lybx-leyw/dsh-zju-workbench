### 现场证据（可复现）

**证据 ①：现实现只匹配 `path`，正文完全不参与。**

复刻 `buildRows` 的过滤分支（`2026-10-26` 沙箱实跑）：

```
查询 '动量'   → 命中 1 条: ['课程/动量守恒定律']
查询 '碰撞'   → 命中 0 条: []                       ← 唯一相关的那篇正文首句就是「碰撞前后…」
```

三篇笔记里，正文含「守恒」的有 2 篇、含「定律」的有 2 篇，**现实现都只答 1 条**。

**证据 ②：上游默认分词对中文无效，必须外接。**

同一批文档喂 `minisearch@7.2.0`：

| 查询 | 默认分词 | 接 `Intl.Segmenter('zh')` |
| --- | --- | --- |
| 动量 | **0** | 3 |
| 守恒 | **0** | 3 |
| 碰撞 | **0** | **1** |
| Attention | 1 | 1 |

**证据 ③：过度切分会产假阳性，必须加一层原文复核。**

`Intl.Segmenter` 把「弹道学」切成 `弹道 | 学`。文档 y=`弹道导弹的学理解释` 因此被**误命中**，
且 `combineWith: 'AND'` **兜不住**。加「原文子串复核」后 y 被正确排除。
→ 这就是 TODO-4 要求**两层**的原因。
