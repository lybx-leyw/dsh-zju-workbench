## 一句话

把 CC98 读侧的 UBB 转换从 **「UBB → 纯文本字符串」** 升级为 **「UBB → AST（带原文字符偏移）」**，
让**嵌套引用的层级**与**每段文字在原文中的位置**不再丢失。

## 集成方式：**强化式集成**（重复且可强化），不是「全新」

| 判据 | 结论 | 依据 |
| --- | --- | --- |
| ① 仍是同一个面板 | ✅ | 4 个调用点全在 `packages/dsh-zhiyun-source-cc98/src/reads.js`（`:106` 帖子 / `:347` 简介 / `:384` 通知 / `:430` 私信）。不新建页面、不新增侧栏、不新增插槽 |
| ② 功能仍相似正交 | ✅ | 同一输入（UBB 字符串）、同一出口（正文）；只把**中间表示**从 `string` 换成 `AST`。不是第二套渲染器 |
| ③ 底层多调了更优质实现 | ✅（有条件） | 「嵌套层级」与「字符偏移」本仓**为 0**（string 契约下结构上给不出）。条件是 `[code]` 走本仓正则，见下节 |
| ④ 不属于「重复无增益」 | ✅ | 若只当"又一个 UBB→文本转换器"则是重复；但它提供的是**本仓输出类型给不出的维度**，属升级而非并列替换 |

### ⚠ 依赖写法：全部是 `"*"`

实测 `npm install @bbob/core@4.4.1 @bbob/preset-html5@4.4.1` 后逐个读
`node_modules/@bbob/*/package.json`：

```
@bbob/core          4.4.1  deps={"@bbob/parser":"*","@bbob/plugin-helper":"*","@bbob/types":"*"}
@bbob/parser        4.4.1  deps={"@bbob/plugin-helper":"*","@bbob/types":"*"}
@bbob/preset-html5  4.4.1  deps={"@bbob/plugin-helper":"*","@bbob/preset":"*","@bbob/types":"*"}
```

后果：**只锁顶层两个版本等于没锁** —— 上游随时可能把 `@bbob/parser` 推到 5.x 而 `@bbob/core@4.4.1` 不动。
因此本骨架 `package.json` **把 6 个包全部写死**（`"4.4.1"`，无 `^`、无 `~`）。
副作用：两处 `"*"` 之间的版本会被 npm 去重成同一份（当前实测 6 个包只有一个版本），**行为可预期**。

## ⚠ 风险：`[code]` 默认会被误解析（**评审前置条件**）

实测（`@bbob/parser@4.4.1`）：

```js
parse('[code]if [b]x[/b] > 1[/code]')
// → { tag:"code", content:[ "if", " ", { tag:"b", content:["x"] }, " ", ">", " ", "1" ] }
//                          ^^^^^^^^^^^^^^^^^^^^ [b] 被当成真标签
```

CC98 技术版**大量**贴含方括号的代码。直接接管会**改坏正文**（丢方括号、变粗体），
这不是"少个功能"，是**让现有输出变差** —— 违反「不得简单集成、不得劣化」的前提。

### 两种修法，以及为什么必须选缝合层

| 方案 | 语义 | 代价 |
| --- | --- | --- |
| A. `{ contextFreeTags: ['code'] }` | ✅ 内容不再解释 | ⚠ 内容被切成多段（`"[", "b]x", "[", "/b]"`）；**块内偏移失效**，而偏移正是本候选的主要卖点 |
| **B. 缝合层**（本骨架采用） | ✅ 内容原样，**偏移也保住** | 需要先摘出 `[code]` 段、再做偏移重算（TODO-C1） |

> **只报"能修"不报"修完丢什么"，等于没测。** 方案 A 修好了语义却废掉了本包的立身之本。

## 实测：方言覆盖

| 输入 | BBob 结果 | 判定 |
| --- | --- | --- |
| `[upload=2]url[/upload]` | `{tag:"upload", attrs:{2:2}}` | ✅ |
| `[upload]url`（无闭合） | `{tag:"upload"}` + **兄弟**字符串 `url` | ⚠ 需重组（TODO-C3） |
| `[ac01][em02][CC9801][ms01][tb01]` | 五个独立 tag 节点 | ✅ 编号保留（本仓压成 `[表情]`，丢信息） |
| `[bili]BV…[/bili]` | `{tag:"bili"}` | ✅ |
| `[quote]a[quote]b[/quote]c[/quote]` | **两层** `{tag:"quote"}` 嵌套 | ✅ **本仓给不出** |
| `[size=5][align=center]x[/align][/size]` | 两层属性节点 | ✅ 属性保留 |
| `[code]if [b]x[/b] > 1[/code]` | `[b]` 被当真标签 | ❌ 见上节 |
| `[img]url[/img]` | `{tag:"img", content:["url"]}` | ✅ |
