## 为什么值得强化（本仓现状）

`packages/dsh-zhiyun-source-cc98` 的 `cc98.search` 直通 `GET /topic/search`，
**只按标题匹配**，拿到什么就返回什么。上游 README 的实测结论是：

> 实测**10 条里只有 1 条真有附件**；真正的资料帖标题往往不含课程名
> （叫「XX 资源楼」「XX 课程总结」），关键词搜索根本捞不到。

上游对此做了三件本仓缺的事：**帖子类型分拣**（卖书 / 求资料 / 资源 / 讨论）、
**多楼层找附件**（资料常在 2、3 楼而非楼主层）、**附件直链解析**。
其中附件解析有一条**实测修正**值得直接抄进本仓文档：

> CC98 v4 正文是 **Markdown**，附件就是普通的 Markdown 链接
> `[显示名](https://file.cc98.org/v4-upload/.../xxx.pdf)`；
> 旧假设的 `[upload=12345]…[/upload]` UBB 占位符在 24 帖 / 105 楼实测里**一次都没出现**。
