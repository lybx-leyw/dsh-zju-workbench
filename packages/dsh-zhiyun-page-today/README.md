# dsh-zhiyun-page-today

「今天」页：今天的课表、已采纳的题、上次打开的那一节，以及今天到期还没勾掉的事。

**改这一页的东西都在这里**：页头文案、课表投影、空状态、到期列表。月历、编辑和拆分仍在规划页，不搬过来。

## 边界

- `inject: ['slots']`。课表不直接找课堂包，而是 `ctx.inject(['zhiyunStudyController'], …)` 惰性取学习控制器。领域包停用时这一页不注册，外壳显示占位，不会把整个前端拖成 pending。
- 注册插槽时 `priority: 10`，外部扩展用默认 0 就能盖住这一页。
- 未登录去个人页。`meta.complete !== true`，或某节没有合法起止时间时，不列出节次，避免把没收全的课表画成今天的全部安排。最近在看只显示这个账号上次打开的那一节，不拿解析时间代替。插空完成只列已采纳的题，点进去打开那一节的出题页。
- 今天到期不把规划包写成硬依赖，也不在浏览器里找宿主服务。它读规划页同一条回环接口 `GET /_dsh/zhiyun-planning`。规划包没装、接口拒绝、某一侧没读到，或今天没有到期的事，这一栏不出现，也不报错。只列本机规划、学在浙大待办、拼题 A 里截止日期落在上海今天、且还没勾掉的条目。本机勾了是做完；平台勾了只是不再提醒。点一行进规划页。已经拆成子项的那条原文不重复列出。页不在视口里时不发这次请求。
- 点一节课：课程列表里能对上 `courseId` 就进学习页并选中这门课，对不上也去学习页，在那里自己挑一门课。

## 插槽

在 `zhiyun.today.content` 注册内容。声明 `children` 的是外壳。

## 文件

| 文件 | 职责 |
| --- | --- |
| `src/client.jsx` | 页面：未登录、读取中、失败、没收全、今天的课 |
| `src/agenda.js` | 纯函数：上海时区时刻，以及现在 / 接下来 / 已结束 |
| `src/due.js` | 纯函数：上海今天到期、还没勾掉的规划与待办 |
| `src/style.css` | 课表行。外壳的 `.zy-*` 仍负责页头和空行 |
