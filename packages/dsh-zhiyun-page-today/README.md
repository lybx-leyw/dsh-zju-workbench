# dsh-zhiyun-page-today

「今天」页：今天的课表，加上还没接入的插空任务和最近进度。

**改这一页的东西都在这里**：页头文案、课表投影、空状态。日历和自建计划以后也属于本包，这一轮不做。

## 边界

- `inject: ['slots']`。课表不直接找课堂包，而是 `ctx.inject(['zhiyunStudyController'], …)` 惰性取学习控制器。领域包停用时这一页不注册，外壳显示占位，不会把整个前端拖成 pending。
- 注册插槽时 `priority: 10`，外部扩展用默认 0 就能盖住这一页。
- 未登录去个人页。`meta.complete !== true`，或某节没有合法起止时间时，不列出节次，避免把没收全的课表画成今天的全部安排。
- 点一节课：课程列表里能对上 `courseId` 就进学习页并选中这门课，对不上就去我的课。

## 插槽

在 `zhiyun.today.content` 注册内容。声明 `children` 的是外壳。

## 文件

| 文件 | 职责 |
| --- | --- |
| `src/client.jsx` | 页面：未登录、读取中、失败、没收全、今天的课 |

| `src/style.css` | 课表行。外壳的 `.zy-*` 仍负责页头和空行 |
