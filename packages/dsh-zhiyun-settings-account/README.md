# dsh-zhiyun-settings-account

智云 Pro 的**账号与数据**：头像登录对话框的正文，以及原生设置浮窗里的「账号与数据」分区。

早先这两块住在「个人」页（`dsh-zhiyun-page-me`）。那一页除它们之外没有别的内容，于是一整页只为承载两个设置项 —— 现在页面已删除，两块各自挂到该在的位置。

## 两个注册点

| 插槽 | 内容 | 谁声明 children |
| --- | --- | --- |
| `sidebar.account.signin` | 头像 → 登录 对话框的正文 | 外壳 |
| `settings.section` | 原生设置浮窗里的「账号与数据」分区（`id: account-data`, `order: 10`） | 宿主 `ui-settings-general` |

`order: 10` 排在「网络代理」（20）、「浙大一卡通」（60）之前：账号与数据是用户最先想确认的一件事，具体凭据配置往后排。

## 当前都是占位

两块都还没有真实数据：账号状态要等平台账号体系落地，数据统计要先有采集口径。文案明确写"在等什么"，而不是摆一句「暂无数据」—— 后者读起来像故障。

## ⚠️ 不要在这里加浙大账号密码输入框

浙大凭证是**宿主凭据**，由 `dsh-zhiyun-source-card` 的「浙大一卡通」分区读写，智云课堂与学在浙大共用。这个对话框将来接的是**工作台自己的账号体系**，两者不能混：

- 把浙大密码输入框放回来，用户会以为"登录这个工作台 = 登录浙大课堂"；
- 凭证一旦落进两个地方，改一个不改另一个就会出现"看着已登录、实际读不到数据"。

需要引导用户去配浙大账号时，只写指路线索（「设置 → 浙大一卡通」），不放表单。

## 停用本包

登录对话框与「账号与数据」分区一起消失，其余功能不受影响 —— 设置浮窗仍由宿主提供，其他分区照常。不需要同步改壳或 profile。
