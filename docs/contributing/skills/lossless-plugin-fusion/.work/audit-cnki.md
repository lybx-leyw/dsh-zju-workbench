### B2 的具体影响（代理实测推演）

`expireTime` / `expiresIn` 在上游从不出现 → 恒 `undefined` → 永远走 `20*60` 兜底。
更糟的是：

```js
expiresAt: this.now() + (ttl > 1000 ? ttl : ttl * 1000)
```

`ttl = 1200`（20 分钟的秒数）→ `1200 > 1000` 成立 → **当作毫秒** → `expiresAt = now + 1200ms`。

**代码写的「20 分钟」，运行时是「1.2 秒」。**

## 次要（10 条）+ 建议（4 条）

代理还列出 S1–S10 与 A1–A4，其中值得记的：

- **S2**：缺 60 秒安全余量（上游 `usable()` 有），剩 1 秒的会话会被拿去发请求
- **S4**：无 429 / 重定向识别 → 302 到登录页会变成「结果不是预期的表格」
- **S5**：滑块检测是关键词启发式，**误判与漏判都成立**
- **S10**：服务面缺 `login({fresh})` 与 `logout()`，`ensure(fresh)` 已支持但**没有入口能递进去**

## 做得对的地方（代理如实列了 10 条）

1. **`queryJson()` 是全包质量最高的一段** —— 12 个顶层键、`gradetxt-N` 的过滤后重编号、`TOPRANK`、`BETWEEN`+`Value2`、`core` 的 `Logic=1`、`KuaKuCode` 二态，**逐字段逐字符与上游一致**
2. **`allOf()` 修掉了上游的死代码** —— 上游的 `/^[*+]+$/.test(term)` 在 `quote()` 之后判，恒为 false，那段永不触发。本仓改在 `quote` 之前判，是**真修正**
3. 三个常量 `Object.freeze`，`TYPES`/`CORE`/`SORTS` 逐字符一致
4. `CnkiSession` 的依赖注入干净（`request`/`load`/`save`/`now` 全注入）
5. 层合规干净：只 import tier 0 的 `http`，不注册 AI 工具，route/provide 骨架与兄弟包同构
6. `network: campus` 判断正确且有三重证据
7. 不搬滑块**拼图求解器**是可辩护的范围决定
8. 会话文件不含凭证，明文 JSON 是恰当取舍
9. 错误形状统一
10. 「不编造问题」—— 代理明确说 `quote` 字符集、`<tbody>` 提取、空结果判据等**确实**与上游一致
