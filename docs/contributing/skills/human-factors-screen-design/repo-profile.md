## 1. 字号（`--zy-fs-*`）

视觉角度按 **CJK 0.88 em / 600 mm / 96 ppi** 推导（见 [ch11](chapters/ch11-cjk-typography.md)）。

| Token | px | arcmin | 判定（16′ 下限） | 用途 |
| --- | --- | --- | --- | --- |
| `--zy-fs-meta` | 11 | **14.7′** | ✗ 不达标 | 仅限非关键信息（时间戳、计数、装饰标签） |
| `--zy-fs-sm` | 12 | **16.0′** | ✓ 压线 | 次要正文、表格、元信息 |
| `--zy-fs-base` | 13 | **17.3′** | ✓ | 正文默认 |
| `--zy-fs-md` | 14 | 18.7′ | ✓ | 强调正文、按钮 |
| `--zy-fs-lg` | 17 | 22.7′ | ✓ 舒适 | 区块标题 |
| `--zy-fs-xl` | 21 | 28.0′ | ✓ | 页面副标题 |
| `--zy-fs-display` | 24 | 32.0′ | ✓ | 页面主标题 |

**规则**

1. 正文 **≥13 px**；长文（论文/笔记/报告）**≥14 px**。
2. 必须读的元信息 **≥12 px**。11 px **不达 legibility floor**，只能承载可忽略的信息，
   且对比度必须 ≥4.5:1。
3. **9–10 px 一律禁止用于中文**。

**待决策**：`--zy-fs-meta` 当前 11 px（14.7′），低于 16′。建议上调至 12 px，或明确把它
限定为「装饰性/非必要信息」。这是一条**已知偏差**，不是已解决项。

## 2. 对比度（实测，2026-10-17）

| 组合 | 浅色 | 深色 |

| `--zy-text` on `--zy-bg` | **13.48:1** | **14.29:1** |
| `--zy-text` on `--zy-surface` | **14.46:1** | **12.72:1** |
| `--zy-secondary` on `--zy-bg` | 5.01:1 ✓ | 8.36:1 ✓ |
| `--zy-muted` on `--zy-bg` | **4.60:1** ✓ | 5.93:1 ✓ |
| `--zy-muted` on `--zy-surface` | **4.93:1** ✓ | 5.27:1 ✓ |

**规则**：正文 4.5:1（AA）；大字（≥18 pt / 24 px）与非文本 3:1；暗色与浅色**分别校验**，
不能只测一套。

> 历史：`--zy-muted` 原为 `#777e85`（3.83:1），2026-10-17 调至 `#6b7178` 达标。

## 3. 目标尺寸

| 元素 | 实测 | 判定 |
| --- | --- | --- |
| 导轨项 `.zy-rail-item` | 34×34 px | ✓ AA（≥24） |
| 主按钮 `.zs-button` | min-height 40 px | ✓ AA |
| 标签页 `.zs-tabs button` | padding 12px → ≈40 px | ✓ |
| 开关 `.zpl-switch input` | 15×15 px | ⚠ 小于 24，需确认 label 的 hit area ≥24 |

**规则**：Web/桌面 **≥24×24**（AA）、**≥44×44**（AAA）；触控 **≥9.5 mm**。
**命中区**按点击区域算，不是可见图形（WCAG 2.5.8）。

## 4. 行宽（measure）

- `.zy-content`：`max-width: 980px` + `padding: 0 48px` → 内容宽 **884 px**。
- 13 px 汉字 → 约 **68 字/行**，**超过 40 汉字上限**（WCAG 1.4.8 AAA，见 ch11）。
- 现状可接受的部分：多数页面是卡片/列表（短文本），不是长文。
- **长文场景**（论文页、笔记页、digest）应约束到 **40 em ≈ 520 px**（13 px 时）。
