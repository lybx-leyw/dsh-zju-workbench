# Ch 17 · Data display (tables, lists, charts)

> **状态声明：本章是数据界面实践，不是标准原文。**
> 对比度/颜色引用 ch03；密度与间距引用 ch02；目标尺寸引用 ch06。

---

## 17.1 表格

| 项 | 建议 | 理由 |
|---|---|---|
| 行高 | 32–40 px（桌面） | 低于 32 会挤，高于 44 浪费 |
| 表头 | 固定、加粗、与内容左对齐 | 滚动时仍知道列含义 |
| 数字列 | **右对齐 + `tabular-nums`** | 位数对齐才能比较 |
| 文本列 | 左对齐 | 符合阅读方向 |
| 斑马纹 | **可选**，优先用行分隔线 | 斑马纹会增加视觉噪声（ch02 密度） |
| 边框 | 少而准：外框 + 行线，避免全网格 | 全网格 = 噪声 |
| 空单元格 | 用「—」而不是空白 | 空白无法区分「无值」与「加载中」 |
| 长文本 | 截断 + `title` | 见 ch15.7 |
| 排序 | 表头可点，当前排序可见 | 不要让用户猜 |

**移动/窄窗**：表格不要横向挤压 → 改为**卡片列表**（每行一张卡），或保留关键列 + 展开详情。

---

## 17.2 列表

- 列表优于卡片网格，当**需要扫描比较**时（本仓库「插件」页即列表）。
- 每行结构固定：主信息（一行）+ 次要信息（一行）+ 操作（右侧）。
- 操作不要每行都显示全部按钮；悬停/聚焦显示，或收进「···」。
- 行的可点击区域 = 整行（但内部按钮要阻止冒泡）。

---

## 17.3 图表选型

| 目的 | 用 | 不用 |
|---|---|---|
| 比较类别 | 条形图（横向更易读长标签） | 饼图（超过 3 类难比） |
| 趋势 | 折线图 | 面积图堆叠过多 |
| 分布 | 直方图 / 箱线图 | 3D 任何图 |
| 关系 | 散点图 | 双 Y 轴（易误导） |
| 占比 | 堆叠条（少量类别） | 环形图 + 图例来回看 |

规则：

- **坐标轴从 0 开始**（条形图必须；折线可例外但要标注）。
- 不要用**双 Y 轴**掩盖量纲差异。
- 颜色不超过 5–7 类；超过用**分面**而不是更多颜色（ch03 的颜色数量限制）。
- 图例与直接标注：优先**直接标注**在线上，减少来回看。

---

## 17.4 数字与单位

- 精度与数据一致（ch15.6）。
- 大数字用**可读单位**（`1.2 万` 而不是 `12000`；但在表格里保留精确值）。
- 百分比变化要说明**基数**（「增长 20%」→「从 100 增至 120」）。
- 负数用 `−`（U+2212）而不是连字符。

---

## 17.5 空数据与异常

- **无数据**：说明原因 + 下一步（ch14.2）。
- **部分缺失**：图表断线而不是补 0（补 0 会造假）。
- **异常值**：保留但标注，不要静默裁剪。
- **加载中**：骨架屏形状接近真实表格（ch14.3）。

## 17.6 本仓库映射

| 界面 | 形态 | 注意 |
|---|---|---|
| 「我的课」 | 两层列表（课程 → 节次） | 行内展开，位置稳定（ch13.4） |
| 成绩/统计 | 数字 + 单位 | `tabular-nums`；精度一致 |
| 「插件」页 | 列表 + 状态点 + 徽章 | 状态不能只靠颜色（ch03） |
| 课表（周视图） | 网格 | 窄窗改为日视图或列表 |
| 生态雷达报告 | 表格 | 仓库/类型/许可/分级四列固定 |

## 17.7 检查清单

- [ ] 数字列右对齐且等宽
- [ ] 表头固定/可见
- [ ] 空值与零值可区分
- [ ] 图表坐标轴从 0 开始（条形）
- [ ] 颜色类别 ≤7，且不只靠颜色
- [ ] 窄窗有替代布局
