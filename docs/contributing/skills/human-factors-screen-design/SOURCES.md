## Why each source is in the set

### FAA Human Factors Design Standard (HF-STD-001B)

- **Local file**: `FAA-HF-STD-001B.pdf`
- **Canonical page**: <https://hf.tc.faa.gov/publications/2016-12-human-factors-design-standard/>
- **Retrieved from**: <https://rosap.ntl.bts.gov/view/dot/71693/dot_71693_DS1.pdf>
- **Licence**: US Government work - public domain
- **Role in this set**: The most directly actionable engineering rulebook for this task. Contains hard numeric requirements for display character height, stroke width, contrast, line spacing, colour coding, alarms, and - crucially - explicit min/default/max rules for user-adjustable parameters, which is exactly the 'active adjustment default value' question.

### NUREG-0700 Rev.4: Human-System Interface Design Review Guidelines

- **Local file**: `NUREG-0700-Rev4.pdf`
- **Canonical page**: <https://www.nrc.gov/regulations-legislation/nureg-series-publications/publications-prepared-by-nrc-staff/human-system-interface-design-review-guidelines-nureg-0700/r4>

NOTE: identifying the genuine Rev.4 took two attempts - the URL first assumed to be Rev.4 (ML20134N366.pdf) is actually Rev.1 Vol.1, and nrc.gov returns 403 to unadorned requests. ### NUREG-0700 Rev.1 Vol.1: Human-System Interface Design Review Guideline

- **Canonical page**: <https://www.nrc.gov/regulations-legislation/nureg-series-publications/publications-prepared-by-nrc-staff/human-system-interface-design-review-guidelines-nureg-0700>
- **Retrieved from**: <https://www.nrc.gov/docs/ML2013/ML20134N366.pdf>
- **Licence**: US Government work - public domain
- **Role in this set**: Retained as the superseded historical revision, and because it holds numeric rules Rev.4 dropped - above all the classic character-height-vs-viewing-distance relationship (15 min arc = viewing distance x 0.004 minimum; 20 min arc = x 0.006 preferred) and the detailed stroke-width, matrix-size and line-length tables. QUALITY CAUTION: this PDF is a 300 ppi scan with an OCR text layer and non-embedded fonts. Its prose contains OCR artefacts (e.g. 'nunimuns' for 'minimum', 'altematives' for 'alternatives'). Sampled inspection found the NUMBERS intact and the OCR damage confined to words, but any figure taken from this file should be cross-checked against Rev.4 or the original page image before being relied on.

### FAA-HF-STD-010A: Color Use in Air Traffic Control System Displays

- **Local file**: `FAA-HF-STD-010A-Color-Use-ATC-Displays.pdf`
- **Canonical page**: <https://rosap.ntl.bts.gov/view/dot/92012>
- **Retrieved from**: <https://rosap.ntl.bts.gov/view/dot/92012/dot_92012_DS1.pdf>
- **Licence**: US Government work - public domain
- **Role in this set**: The single richest source in this set for normative, implementable numbers. Its Table 5.6-I gives character-height requirements as arcmin of visual angle - i.e. resolution- and distance-independent - synthesized from ANSI/HFES 100 and 200, ISO 9241-303, MIL-STD-1472G, NASA HIDH and NUREG-0700. Also carries quantitative colour-difference rules (CIELUV dE), luminance and contrast limits, palette size caps, and explicit minimum/default/maximum rules for user-adjustable display settings. NOTE: this file was originally mis-titled 'DOT Human Factors Volume 1' from the ROSAP landing page; the document's own title page identifies it as FAA-HF-STD-010A.

## Retrieval notes (host-specific, kept because they cost real time to discover)

This machine's TLS setup makes the obvious approach fail:

- `git` and `curl` default to the **schannel** TLS backend, which fails here with
  `schannel: AcquireCredentialsHandle failed: SEC_E_NO_CREDENTIALS (0x8009030e)`.
  Cloning or downloading without forcing another backend does not work.
- The host reaches the internet through an **HTTP proxy** in that environment. Python's `urllib` picks the proxy up from `HTTPS_PROXY` automatically.
- Several `.gov` hosts (`rosap.ntl.bts.gov`, `www.nrc.gov`) return **403** to a bare
  `Mozilla/5.0` User-Agent. A complete desktop-browser header set is required.

`tools/fetch_sources.py` encodes all three fixes and is the supported way to re-fetch:

```bash
python tools/fetch_sources.py          # fetch whatever is missing
python tools/fetch_sources.py --list   # show manifest and on-disk status
python tools/write_provenance.py --check   # verify local hashes have not drifted
```
