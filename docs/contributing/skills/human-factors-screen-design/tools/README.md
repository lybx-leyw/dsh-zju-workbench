# Tools

These are the scripts that produced and verified this skill. They are included so the
knowledge base can be **re-derived and re-verified**, not just read.

## Layout contract

Most of these tools operate on a *pipeline working layout*, which is the layout they were
written for and the one in which they were verified:

```
<work>/
├── sources/            # downloaded source documents (not vendored here)
│   ├── *.pdf / *.html
│   └── SOURCES.md      # generated by write_provenance.py
├── extracted/
│   ├── *.txt           # layout-preserved text, one per source
│   └── mined/*.mined.md  # per-source rule extractions
└── tools/              # these scripts
```

`SOURCES.md` in this folder is a **copy** of the generated file from that layout; the tools
will look for `../sources/SOURCES.md` and `../extracted/mined/` relative to themselves.

## Which tools are standalone

| Tool | Needs extra checkout? | What it does |
|---|---|---|
| [`fetch_sources.py`](fetch_sources.py) | no | Downloads sources listed in [`sources.manifest.json`](sources.manifest.json). Encodes the TLS/proxy/User-Agent workarounds described in `SOURCES.md`. Run `--list` to see the manifest and on-disk status. |
| [`write_provenance.py`](write_provenance.py) | no | Hashes every file in `sources/` and emits `sources/SOURCES.md`. `--check` verifies no file has drifted. |
| [`html_to_text.py`](html_to_text.py) | no | Converts a saved HTML document (e.g. WCAG) to readable text. |
| [`verify_numbers.py`](verify_numbers.py) | no | Samples numeric claims from `extracted/mined/*.mined.md` and checks each occurs in the corresponding source text. This is the tool behind the "99 % of sampled numbers verified" claim. |
| [`build_guideline_index.py`](build_guideline_index.py) | no | Builds a line index of guideline headings, tolerant of OCR-garbled identifiers. |
| [`run_extract.py`](run_extract.py) | **yes** | Wraps the third-party `book-to-skill` extractor, patching two environment blockers. See its docstring; it needs a `book-to-skill` checkout and exits with instructions if absent. |

## Re-running the pipeline

```bash
python tools/fetch_sources.py            # download whatever is missing
python tools/write_provenance.py         # regenerate SOURCES.md
python tools/verify_numbers.py           # re-verify numeric fidelity
python tools/write_provenance.py --check # confirm nothing drifted
```

The mining stage (source text → `*.mined.md`) and the chapter-writing stage were performed by
agents, not by a script. The prompts that produced them, and the rules that keep the output
honest, are documented in the pipeline methodology — the key constraint being **never invent
or round a number; omit rather than guess**, with a section citation on every claim.
