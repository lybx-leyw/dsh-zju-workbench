**新发现（写入骨架待决点，不改骨架文件）**：上游 `package.json` 的 `files` 字段**只含 `lib` / `assets` / `vendor`**，
`main: lib/index.js` 读的是**已编译产物**，而 `git tree` 里 `lib/*.js` 已提交、**无 `src/`、无 `build` 脚本** ——
即「源码即产物」：`client.js` 单文件 **152 KB**。这带来两个后果：

1. **锁 tarball 可行、锁 git 引用不可行**（拉不到构建脚本就无事可做），骨架的 `@local/dsh-zotero: 1.0.1`
   **必须靠 `dsh-zotero-1.0.1.tgz` 挂本地 tarball 或私有 registry**，不能指望 npm（npm 上无此 scope 发布）。
2. 将来做「外围兼容层」时**不要试图改 `client.js`**（152 KB 单文件、无 source map），
   应按骨架 README 既定路线：**弃其客户端，只借 `/zotero/*` 路由**，由 `page-paper` 的 `ReaderFrame` 渲染。
