## 5 · L2 骨架：`packages/radar/dsh-radar-agent-router/`

```
package.json       锁版 dsh-llm-agentrouter@2.6.1（精确，非 ^）；dsh.bundle.patch → ./cordis.patch.yml
cordis.patch.yml   仅一行 insert：id radar-agent-router / name dsh-radar-agent-router
src/index.js       占位 apply()，只打日志、不注册任何东西
src/upstream.js    锁版凭据 + peer `*` 的断言 + UPSTREAM_OVERRIDES = 'llm-pi-ai.providers'
README.md          顶部「未评审、未接入 profile、不可直接使用」；三判据表；R-1..R-5
OWNERS             Owner: shared
```

**没有**：`test/`、`__tests__`、`*.test.*`、`*.spec.*`；
**没有**写入 `profiles/zhiyun-bench/package.json`；**没有**放在 `packages/` 根。

### 关键设计决定：**不复用上游的 patch**

上游 patch 是 `override: llm-pi-ai`（整段覆盖 `providers`），不是 insert。
若直接复用，本仓 profile 会多出一份不在自己 id 下的覆盖层，回滚时无从下手。
因此本骨架**只 insert 自己**，由 `src/index.js` 在运行时 import 上游并 apply ——
上游的覆盖成为**本包依赖的一部分**，而不是并列的另一个 bundle。
