**为什么未直接锁版挂载（这是「未评审」的全部理由）**

1. 在插件页旁边**多出一块自己的面板**（违反条件①，等于换掉本仓 `dsh-zhiyun-shell-ui` 的壳）；
2. 引入凭据面（`lib/` 里有 MCP OAuth 授权）；
3. 与在册 `dsh-radar-mcp-manager`（MCP 管理骨架）**职责重叠**。

⇒ 因此骨架 `dsh-radar-plugin-caps` **不锁它**，而是按「只取能力契约」处理：`dependencies` 为空、
`src/upstream.js` 只记录**接口形状**（`tool × count × ms × errors`）与**待核项**。这是本仓
`dsh-radar-paper-evidence`（★0 非 npm 包）先例的同类处理。
