### 2.1 🟢 `piggymon907/codex-paper-reader-skill` — **本轮骨架**

| 项 | 值 |

| 活跃度 | ★0 · push 2026-08-21 · 建仓 2026-08-19 · 189 KB / 约 40 项 |
| 学生场景 | 论文精读（生物/物理/生医类论文的「研究生级」读法） |
| **与现有功能的关系** | **重复且可强化** ✅ |
| 分级 | **🟢 可直接集成（限「契约」层面）** |

**它到底补了哪一级**

「论文阅读」页（`dsh-zhiyun-page-paper`）已有三级回答粒度：篇（右侧抽屉）、选区（悬停翻译）、
**页**（`AssistantDrawer.jsx` 的页码 chip，可点跳转）。缺的是**块/句**：

| 粒度 | 问法 | 落点 |
| --- | --- | --- |
| 篇 | 「这篇讲了什么」 | 整段回答 |
| 选区 | 「这句英文什么意思」 | 浮层译文 |
| 页 | 「这个结论在第几页」 | **第 7 页页首** |
| **块/句** | 「原话是**哪一句**、**没**说什么」 | **p007-b014** ← 缺 |

上游给的不是 UI，是**契约**（`references/data-contract.md` + `assets/reader/reader.js` 52.7 KB）：

- 坐标：PDF point、左上原点，页面尺寸留服务端，**只在浏览器换百分比**；
- 断裂行：一个标记挂多个 `bboxes`；图/表/公式另给 `visual_bbox` 供裁切放大；
- **三字段强制**：`supports` / `does_not_support` / `limitations` —— 本仓**完全没有**「没说什么」这一维；
- 单一证据对象同时喂侧栏与全屏，**禁止**两套解释；
- 构建身份不可变：`run_manifest.json` 记 `generator.skill_version` + 四项文本质量计数
  （`long_alpha_runs` / `cid_artifacts` / `suspicious_glue_boundaries` / `damaged_formula_references`）。

最后一项最值钱：本仓论文页的文本来自上游转录，而 PDF 抽取的三大老毛病（连写字母串、
CID 乱码、公式贴边）**恰好**就是这四个计数要抓的。现在页面上只有「转录状态」一个布尔量。

**强化式集成三条判据**

| 判据 | 结论 |
| --- | --- |
| ① 仍是同一个面板 | ✔ 不注册新页面 / 不注册 slot；锚点层画在 `ReaderFrame` 的**同源 iframe 内部**，与 `frame-theme.js` 走同一注入通道 |
| ② 功能仍相似正交 | ✔ 正交在**粒度**（页 → 块/句），不是把「选文本翻译」重做一遍 |
| ③ 底层多调了更优质实现 | ⚠ **打折扣** —— 只有前端渲染与契约可用，抽取层是 Python，见下 |

**⚠ 三条必须先看的事实**

1. **不可锁版**：它不是 npm 包、也没有 `package.json`；`requirements.txt` 仅 24 B，
   9 个抽取/校验脚本全是 Python（`extract_paper.py` 25.7 KB、`validate_reader.py` 41.9 KB 等）。
   ⇒ 本仓 Node 宿主**不能**装上它。可选项只有 **(a) 只取契约** 或 **(b) 引 Python 旁路**。
   骨架**默认按 (a) 写**，但 (b) 属架构级决定，**超出雷达裁决权**。
2. **第一道闸门未过**：上游 reader 是整页渲染形态（`#pageImage` + `#pageCanvas` + `#markerLayer`），
   要画锚点必须有「每页位图」+「块级 bbox」。本仓 `/paper-reader/` 的 24 条路由**是否提供**这两样，
   **本轮未核实**（`page-paper/src/library.js` 只暴露调用面，不暴露字段）。
   若只能靠 pdf.js text layer 现算 bbox，**精度不达标则整包驳回**。
3. **三字段需要质检**：上游是「LLM 填 + `teaching_audit.py` 审计 + `validate_reader.py` 质检」三道。
   本仓若只有 LLM 填，「说没说什么」会变成**编造**，比不显示更糟 ⇒ 骨架里定为**没有质检就不上线这三个字段**。

**下一步**：人工评审先过 TODO-0（路由字段核实）。过了再决定 (a)/(b)；不过则整目录删除，
改登记为「能力提取（坐标契约）」。
