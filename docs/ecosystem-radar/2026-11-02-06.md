**为何更优（逐条对照上游源码）：**

| 能力 | 上游实现 | 价值 |
| --- | --- | --- |
| `第X周` 前缀剥离 | `normalizeText(spec).replace(/第/g,'')` **先剥后切** | 不剥则切分后正则失配 → **静默丢课** |
| 全角归一 | `～ — － 至` → `~`；全角括号 / 逗号 → 半角；`\u00a0` → 空格 | 浙大课表常见全角 `～`，不归一则整学期解析不出 |
| 单双周 + 区间复合 | `parity` 与 `start..end` 同时生效，`week % 2 === parity` | 手写常丢单双标记 |
| 周日双写法 | `dayMap` 同时含 `日` 与 `天` | 漏一个丢周日的课 |
| `.ics` 属性 | `VALARM`(`TRIGGER:-PT{n}M`) + `VTIMEZONE`(TZID 标准块) + `TRANSP:OPAQUE` | 提醒不是「理论上支持」，是写进文件的 |

**上游的两处不足（本项目侧须补，已在骨架里标注）：**

1. 区间单调性未校验：`16~3` 产出空数组且**不报错**。
2. 周次上限硬编码 `30`：浙大夏季短学期可能到第 31 周。

**为何仍是 B 类而非 A 类**：上游是浏览器扩展，`package.json` 为 `"private": true`，
既无 `dsh.bundle.patch`，也无法从 npm 锁版 → **只能源码级借鉴**，不做「锁版挂载」。

**已生成骨架**：`packages/radar/dsh-radar-timetable-calendar/`
（含 `package.json` 空依赖 / `cordis.patch.yml` / `src/index.js` / `src/upstream.js` /
`README.md` / `ATTRIBUTION.md` / `OWNERS`）
