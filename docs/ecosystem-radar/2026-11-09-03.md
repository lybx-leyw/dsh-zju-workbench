#### 4.1.2 可迁移的是什么

上游是 MIT、**可以摘码**，但它的实现绑死在 Obsidian 的 `Plugin` / vault / callout 三条 API 上，
搬过来等于重写。**可迁移的是三条决策**（已写入骨架 `BORROWED_CONTRACTS`）：

- **C-1 引擎可切换、默认本地** —— 默认云 OCR 等于用户第一次点就外联；
- **C-2 文本层优先** —— 论文页已解出文本层，再 OCR 一遍是双重成本 + 双重误差；
- **C-3 结果写进正文、不另建索引** —— 一份数据一条索引，旁挂索引会与正文索引互相漂移。
