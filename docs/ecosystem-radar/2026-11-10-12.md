| `forced alignment phoneme browser` | **0** | 无结果 |

同一个结论在 #2 得到印证：`phoneme ipa language:javascript` 只有 **8** 条，其中**唯一带宽松许可证且有算法价值的是 `RThevenoux/ipa-distance`**。

> **这说明什么**：发音评测在 JS 生态里**不是「有更好的实现可选」，而是「几乎没有实现」**。
> 因此本轮**不存在**「重复且可强化」的 🟢 候选（这与 r166 的 `dsh-dcp` 形成对照：那里是「有更好的后端」，这里是「后端根本不存在」）。
> 真正的可集成层落在**下游**：**音素数据本身**（词典 + 音素集映射），而不是评测算法。

**⚠ 必须写进骨架的风险（已写入 `src/upstream.js`）**

- **R-1 · 只有 ARPAbet，没有 IPA**：上游产出 `K W IH1 K`，**不是** `kwˈɪk`。要显示国际音标必须叠一层 ARPAbet→IPA 映射表（39 个音素 + 3 个重音标记，**映射本身很小，但「哪个口音」要选**：cmudict 是**通用美式**，不含英式 `ɒ/əʊ` 对立）。骨架据此把「映射表」列为**自有实现**，不引第二个上游。
- **R-2 · 体积 4.7 MB / 单文件 `index.js`**：`import { dictionary }` 会**整表进内存**。在浏览器侧（`page-notes` 是 iframe 承载的 React 应用）不可接受。骨架要求：**只在 Node/宿主侧查表**，音素串以**短字符串**下发到客户端；若必须客户端查表，则按需裁切（先取词表首字母分片）。
- **R-3 · 变体与专名覆盖面**：上游键含 `'a(1)'`、`"a's"`、`a42128` 这类**带变体序号与所有格**的键。查词时须先做归一化（小写、去所有格、按 `(n)` 取第一变体），否则 `students` / `student's` 查不到 —— 这是**最常见的集成翻车点**。
- **R-4 · 停更 4 年**：`pushed 2021-08-12`。但它是**数据包**，cmudict 本身也是低频更新的语料；**风险是「新词查不到」，不是「代码坏了」**。锁 `3.0.0` 精确版本，并预留「查不到时回落 TTS 直读」的分支。

#### ③ `RThevenoux/ipa-distance` —— 🔵 **有算法价值，但不适合锁版**

| 项 | 值 |
| --- | --- |
| 类型 | B · 其他 JS |
| 许可证 | **MIT**（`LICENSE` 正文首行 `MIT License`）✅ —— ⚠ **但 `package.json` 写 `ISC`**，两处不一致（见下） |
| npm | `ipa-distance@0.1.3`（**2018-08-03 最后一版**，仅 2 个已发版本；依赖 `ipa-parser ^0.1.0`） |
| 下载量 | **19 次/月** |
| 仓库 | ★8，`pushed 2018-08-03`（**8 年未动**） |
| 学生场景 | 发音打分（「你读的和标准音差多少」） |
| 与现有功能的关系 | **全新**（本仓无任何音素距离实现） |

**它到底做了什么（读码，可复现）**：`data-source/feature-mapping.csv`（8.2 KB）把 IPA 音素映射成**特征集**，生成 `src/data/feature-mapping.json`（81 KB）；
`src/feature-set-sequence-distance.js` 在特征集序列上做**加权 Levenshtein**（`insertionCost = deletionCost = 2`，替换代价 = 两个音素特征集的**加权距离**）。
这正是「发音错在哪里、错得多严重」的教科书做法 —— **算法本身是对的、也是有价值的**。

**为什么仍判 🔵 而不出骨架**：

1. **19 次/月的下载量与 8 年停更** ⇒ 不可能作为「更优底层」被信任；锁版只会把一个僵尸依赖拉进工作台。
2. **`package.json license: ISC` vs `LICENSE` 正文 `MIT` 自相矛盾** —— 两者虽都在白名单，但**许可证声明不一致**本身是集成前必须人工核定的项（本任务口径：`NOASSERTION` / 不一致 ⇒ 不采用）。
3. **能力可用「读算法 + 自写 60 行」拿到**：加权 Levenshtein 是公开算法，特征表口径写在 `feature-mapping.csv` 里。
   **借鉴算法思路（不摘码）** 比锁一个僵尸包划算 —— 这正是 🔵 的用途。

> **登记为 🔵，并在 ATTRIBUTION 口径上留一条备注**：若日后自写音素距离，需按 CONTRIBUTING 3.3 注明「参考 `ipa-distance` 的特征集 + 加权 Levenshtein 思路」。
