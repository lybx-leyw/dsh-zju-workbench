## 3. 评估明细

### 3.1 `yunhuantian/dsh-plugin-hub` — 🟡

- **类型**：A · 原生 DSH 插件包（`dsh.bundle.patch` + `cordis.patch.yml`）
- **与现有功能的关系**：**重复且可强化**（插件页）。三条判据：仍是「插件」页（它自述**不新增入口**，挂进官方插件页）；功能正交（现有答「我手上这几个包谁依赖谁、能不能关」，它答「生态里还有什么、装进去会不会冲突」）；底层更优（`pluginConflict` / `dependency graph` / `security scan` / `npm probe` 本仓**零实现**）。
- **为什么**不**判 🟢**：它是 **21 个内部插件打成一个包**、`main` 指向 `lib/host/index.js`、`exports` 有 6+ 子路径 —— 不是「一个库」，锁版挂载等于**一次引入 22 行插件清单**，与「不做第二套启动器」直接冲突。且它的 `pluginConflict` 会与本仓插件页**同时判 plugin 状态**。
- **建议**：只借**一个**能力 —— `hub-ext-npm-probe`（npm 可用性探测），正好补今天检查器的**在线部分**；不接整包。

### 3.2 `NanmiCoder/dsh-plugin-market` — 🟡

- **类型**：A · 原生 DSH 插件包
- **与现有功能的关系**：**重复且可强化**（插件页），但与 `dsh-radar-market`（已挂 `dshmarket@1.66.21`）、`dsh-radar-dsh-web` **三方同质** —— 三者**至少两个不该存在**，这正是 `dsh-radar-dsh-web/README` 自己写下的取舍问题。
- **唯一增量**：**「确定性规则决定能不能装」**（catalog 3,518 → 可一键装 936 → npm 存在 716 → 源码可验 220），模型摘要与标签**只展示、不授权安装**。这条与今天的 F-1 是**同一个问题**（我们恰恰是「没验就锁了」）。
- **建议**：**先不接**，先去读它的 trust tier 规则，把「能不能装」的判定搬到 `radar-baseline-check.mjs`；接不接等 market 三方取舍裁定后再定。

### 3.3 `Yui-Little/dsh-mobile-shell` — 🔵

- **类型**：A · 原生 DSH 插件包（纯 client，`platform: web`）
- **与现有功能的关系**：**重复且无增益**（面对学生场景）。它做的是窄屏适配 + 设置 sheet + 插件市场 + 会话状态面板；本仓 `dsh-zhiyun-shell-ui` 已承担外壳主题与布局，且工作台定位是**桌面**。
- **降 🔵 的硬理由**：仓库 README 徽章写 `v0.1.8`（`package.json` 也是 `0.1.8`），**npm latest 是 `0.7.2`** —— 版本号在三处不一致，锁版时无法确认锁的是哪一版。这类「三处不一致」在 r79 已被记为降级理由。
- **仅作线索**：它的 `Status` 标签页（轮数/步数/TTFT/缓存命中）可以看，但本仓 `context-lens` 已覆盖。

### 3.4 `MorGogh/widget-dock` — 🔵

- **类型**：A · 原生 DSH 插件包
- **与现有功能的关系**：**重复且无增益**。27 张卡片里，余额/Token/成本/上下文/热度图/GitHub/推理强度 —— 本仓 `context-dashboard`、`activity-heatmap`、`context-lens` 已覆盖，且本仓是「页面内一块」，它是「对话两侧常驻拖拽工作台」，**面板形态冲突**（强化式集成第 1 条不成立）。
- **活性**：★4，最后 push 2026-08-15（**73 天前**），25 个文件级 commit 后再无更新。
- **建议**：不接。

### 3.5 `1624318455/dsh-plugin-tts` — ⛔

- **类型**：A · 原生 DSH 插件包（★42，是这批里最活跃的）
- **与现有功能的关系**：**重复且无增益** —— 本仓没有任何「朗读」功能，装了就是**新开一条语音链路**（Edge TTS + RVC + Index-TTS2 + CosyVoice + Google Cloud TTS 五后端），违反「不简单集成重复功能」之外的另一条：**不为单一功能引入重型依赖面**。
