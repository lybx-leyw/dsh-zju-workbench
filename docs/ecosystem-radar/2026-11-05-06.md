## 一、本轮判定轴：GPA 的「分学期」—— 一个算好了却没人画的数

判定轴仍是**先读码、后定向搜**。C 组五个默认词（#1–#5）本轮再次证明枯竭，
所以本轮把预算转向**本仓已有数据 → 上层没接**的接缝。

### 1.1 读码事实（逐条实测）

| 事实 | 位置 |
| --- | --- |
| 教务读取器**已经**产出「总体 / 专业 / **分学期**」三档 GPA | `source-zdbk/src/reads.js:148-169`，返回 `{ overall, major, semesters:[{semester:'2025-2026-1', ...gpaOf(rows)}] }` |
| 单学期对象含 `gpa_5` / `gpa_4_3` / `average_score` / `gpa_credits` / `earned_credits` / `courses` | `source-zdbk/src/parse.js:265-272` |
| 该能力**已**注册成服务与 HTTP 路由 | `source-zdbk/src/index.js:426-431`（`zhiyunZdbk.gpaSummary`）、`:68`（`/api/zhiyun-zdbk`） |
| **前端零消费** | `grep -rn "gpaSummary\|gpa_summary" --include=*.jsx packages/` → **0 命中**；`grep -rn "成绩\|GPA" --include=*.jsx packages/` → **0 命中** |
| 今日页只读到一个数 | `page-today/src/agenda.js` 全文 30 行，只把课表折成 `current/upcoming/finished`；`due.js` 只读到期的待办 |

**断环的精确形状**：不是「本仓没有成绩」，而是——**唯一能回答「这学期比上学期好了吗」的那组数（`semesters[]`）已经算好了，却没有一处界面画它**。
用户在今日页能看到的全部时间信息是「今天几节课」，看不到「这个学期已经过去多少、绩点落在哪个档」。

### 1.2 这与「重复且无增益」的边界在哪

生态里 GPA 相关项目有 **1000+ 个**（#6/#9/#10 三次搜索合计命中 908 条），
但它们**全部**是同一个形状：**用户手敲「课程名 + 学分 + 成绩」→ 出一行数字**。

| 维度 | 生态里的 GPA 计算器 | 本仓现状 | 结论 |
| --- | --- | --- | --- |
| 数据来源 | 手敲 / 上传 Excel / 浏览器 DOM 抓他校教务页 | **教务接口直出**，且已分学期 | 本仓更强 |
| 口径 | 单一套 `4.0` 或 `4.3` 阈值表 | 5 分制 + 4.3 制 + 百分制加权**三档同时给** | 本仓更强 |
| 落点 | 一个独立网页 | 工作台内已有面板 | 本仓更强 |

⇒ 任何「GPA 计算器」接进来都是**重复且无增益**（⛔），这是本轮 10 条 ⛔ 里的 7 条。
**唯一有增益的可能**在 #11 的空白处：`5.0 4.3 gpa conversion` **total = 0** —— 说明
「把教务的 5 分制绩点换算成 4.3 制」这个**口径本身**在开源世界没有标准实现。而本仓
`parse.js:153` 的 `FOUR_THREE = { 5: 4.3, '4.8': 4.2, '4.5': 4.1, '4.2': 4.0 }` 是**踩出来的**私有对应表。

**这构成下轮明确的可搜索目标**（不是本轮结论）：找一个有公开口径依据（学校公开换算文件、留学申请机构的白皮书）的 4.3 制实现，用来**校验**这张表，而不是替掉它。

| `gpa calculator *` | 908 条合计，★≥30 只有 8 个 | **只保留口径词**（见 ③） |

⇒ C 组应当从「功能域名词」彻底转向**「本仓数据 → 上层没接」的接缝搜索**。本轮唯一有效的一击（#11 `total=0`）恰恰来自这种搜法。

### ② 「重复且无增益」的判定要落到**数据来源**，不是落到功能名

本轮 7 条 GPA 计算器功能名完全对口，但它们的数据来源是「手敲/抓 DOM」，
而本仓的来源是**教务接口**。同样叫「算 GPA」，**换上去等于把自动数变回手工数**。
⇒ 建议把这条写进评分口径：**候选的数据来源弱于本仓时，一律 ⛔，不论功能名多对口**。

### ③ 一个 `total = 0` 比十个命中更有信息量

`5.0 4.3 gpa conversion` → **0**。这说明本仓那张 `FOUR_THREE` 表（`5→4.3 / 4.8→4.2 / 4.5→4.1 / 4.2→4.0`）
**在开源世界里没有对应物**，既不是抄来的，也无从校验。下轮该找的是**口径文档**（学校公开换算说明、留学申请白皮书），
用来**验证这张表**，而不是找代码去替换它。
