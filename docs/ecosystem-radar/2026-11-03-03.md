  **不接管 settings 分组** —— 与本仓 `dsh-zhiyun-page-plugins` 同槽位体系，不冲突；
- 触发面：`session/event`（`turn/end` / `approval/asked`）+ `user-questions/request`；
  Web Push 分支要求 `sseClients.size === 0`（**没有页面连着才推**）；

**两条必须写进评审的负面事实**：

1. **peer 依赖是 `@deepseek-ai/{cordis,dsh-session,dsh-credentials,schemastery}`**，
   本仓 `devDependencies` 只有 `@deepseek-ai/dsh-atomic-write`，**没把 `cordis` / `dsh-session` 版本钉住**
   ⇒ 装完才发现 peer 不匹配。接入前必须在真实 profile 里核。
2. **W3C Web Push 要求 HTTPS 或 localhost**。桌面壳满足；但用户若从局域网 IP 访问，
   `PushManager` 存在而 `subscribe` 抛错 —— **静默失效**，必须在前端说清楚。
