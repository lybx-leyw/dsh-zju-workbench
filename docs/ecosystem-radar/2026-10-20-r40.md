### 2.1 本节最重要的一节其实是「L-1」，不是候选

读码时我把本仓 `buildIndex()` 当黑盒探针跑了一遍，**四处行为与它自己的注释不符**。
这些都是**先前的雷达轮次没抓到**的（`tests/vault.test.mjs` 32 条全绿，说明测试也没覆盖到）：

| # | 现象（2026-10-20 实测） | 位置 | 后果 |
| --- | --- | --- | --- |
| **L-1a** | **一篇笔记只被建了一半时，「未建笔记」不入图** | `vault-index.js` 的 `resolve()` 返回 `null` 时只 push 进 `unresolved`，**不建节点** | 实测：`周报.md` 写 `见 [[矩阵]]`、但 `矩阵.md` 还没建 → `edges=0`、`nodes=[周报.md]`、`orphans=["周报.md"]`。**「这篇笔记是孤岛」是假的**——它明明链着一篇（待建的）笔记。Obsidian 里这里会显示为虚线节点 |
| **L-1b** | **同一篇被引用两次 → 两条重边** | `edges.push({from,to,kind})` 无去重 | 实测：`[[A]] 与 [[A]]` → `edges=[A,A]`，`inDegree=2`。反链列表会出现重复条目，「被引用 2 次」与「2 条关系」没有分开 |
| **L-1c** | **缩进 2 空格的代码围栏不被识别** | `links.js` 的 `CODE_FENCE_RE` 只在行首或 `\n` 之后匹配 ` ``` ` | 实测：`'  ```\n  [[A]]\n  ```'` → **A 被当成真链接**。Markdown 允许围栏前有 ≤3 空格缩进（列表里的代码块就是这样） |
| **L-1d** | **`$$` 公式块 / 双反引号 / URL 里的 `[[x]]` 不被排除** | `excludedRanges()` 只处理 ` ``` `、单反引号、单 `$`、`http(s)://` 前缀 | 实测：`'$$\n[[A]]\n$$'`、`'用 ``[[A]]`` 写法'`、`'https://a.com/[[A]]'` 三种都产出真链接 |
