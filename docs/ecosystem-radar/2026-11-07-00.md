## 4. 为什么本轮不出骨架

规则要求骨架「仅 🟢 且许可证明确」，每轮最多 1 个。本轮 **0 个 🟢**：

- 唯一 🟡 的 `dsh-answer-top` 是 ★0、单点行为、20 行以内可自研的任务 —— 为它建一个 `packages/radar/dsh-radar-*` 包（含 `package.json` / `cordis.patch.yml` / `src/` / `OWNERS`）**成本高于收益**，属于「为凑配额而建包」，会稀释 radar 目录的信噪比（该目录已有 121 个包）。
- §3.2.1 的 `simple-reading` 虽是 MIT 且思想契合，但它是 **Obsidian 插件**（`main.js` + `manifest.json`），不是可锁版的 npm 库，且本仓 `pdf-anchor` 骨架已占住同一格。

> **结论**：本轮如实记 0 骨架。规则里「即使无新候选也要有报告」同理适用于「没有值得建包的候选」。
