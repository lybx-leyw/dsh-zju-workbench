## 4. 本轮结论

1. **宽词 `opensheetmusicdisplay OR vexflow`（325）是本轴唯一有效入口** —— 直接命中高质量库；
   其余 9 个词贡献的有效候选为 **0 条 🟢、3 条 🟡**，且**一半是长尾 ★0–★4 项目**。
2. **「视唱练耳 / 耳力训练」子轴一轮即见底**：`solfa …`(0) / `ear training …`(3) 全为
   ★0–★2、两个以上无证 → **建议封板**。
3. **「浏览器 Typst / Tinymist」子轴几乎无货**：都是 Obsidian/编辑器适配器，
   真正的 Tinymist 是 Rust LSP，**不是 JS 项目** → 若要 Typst 路线，应直接锁版 Tinymist **二进制**，
   而不是找 JS 包（**词池里该词可移除**）。
4. **谱面技术路线二选一**：OSMD（渲染） vs VexFlow（更底层、需自带解析）—— 本轮判 OSMD，
   理由是「MusicXML 解析 + 版权字体 + 版式」三件事自研都不现实；VexFlow 只作降级备选。
5. **产品层真实存在的样本是「练习反馈」而非「看谱」**：`Syrinx`（音准检测+逐音打分）、
   `arabesque`（Web MIDI 实时反馈）都比纯渲染更贴学生场景。
   **若人工评审认为「练习反馈」才是真需求，应优先改做 `Syrinx` 的能力提取路径**（同为 Apache-2.0 ✅）。
6. **本轮仍无「浙大特定」项目** —— 该轴与 B 组无交集，属**能力域**而非**场景域**补充。
