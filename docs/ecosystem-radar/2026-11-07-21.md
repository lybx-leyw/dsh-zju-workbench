### 3.1 `cacfd3a/bibtex-js` —— 84★ / MIT —— **⛔ 重复且无增益**

| 项 | 结论 |
| --- | --- |
| 类型 | **B · 其他 JS 项目**（纯解析库，非 DSH 插件） |
| 许可证 | **MIT ✅**（`LICENSE` 首行 `MIT License / Copyright (c) 2017 Maarten Trompper`；npm `bibtex@0.9.0` 的 `license` 亦为 MIT） |
| 学生场景 | 论文 —— 文献库导入 |
| 与现有功能 | **重复且无增益 ⛔** |
| 分级 | ⛔ |

**为什么判 ⛔（这是本轮唯一需要举证的判据③）：**

本仓 `packages/radar/dsh-radar-refs-import` 的骨架**已经选定上游为 `@citation-js/plugin-bibtex@0.9.0`**，
其 README 的实测表 M1–M4 已用真实数据验证过：单条/多条/中文条目/`@inproceedings` 全部能折成 CSL-JSON。
`bibtex-js` 与它做的是**同一件事、同一段链路**（BibTeX 文本 → 结构化条目），且**明显更弱**：

| 维度 | `@citation-js/plugin-bibtex`（已选） | `cacfd3a/bibtex-js` |
| --- | --- | --- |
| 输出格式 | 标准 **CSL-JSON**（下游可直接用） | 自有 AST（`BibEntry` / `BibStringEntry`），**需再写一层映射** |
| RIS 支持 | ✅ 同时覆盖（`plugin-ris`） | ❌ 只做 BibTeX |
| 维护 | 2026-10-22 仍在推 | 仓库 `pushed_at` 2025-10-19，npm **最后发布 2017-09-09**（9 年前） |
| 类型 | TS 源码 + 编译产物 | TS 源码，**npm 包为 2017 年的 ES5 构建** |
| 依赖 | core + 2 插件（682 KB，已知成本） | `dependencies: {}`（**唯一优势**：零依赖、体积小） |

⇒ 「仍是同一个面板 ✅、功能仍相似正交 ✅」两条成立，但**判据③（底层多调了更优质实现）不成立** ——
新候选在同一维度上是**平行且更弱**的实现。按 skill 明文「重复且无增益 → ⛔ 不集成，只登记一行」，**不出骨架**。
若将来评审否决 `refs-import` 的 682 KB 成本，`bibtex-js` 可作为**轻量回退方案**被重新提起 —— 这条已写进 registry 备注。

> **附带的身份核实（本轮新增可疑点，已查清）**：仓库 `cacfd3a/bibtex-js` 的 `package.json` 里
> `repository.url` 指向 `git@github.com:digitalheir/bibtex-js.git`，作者是 Maarten Trompper，
> 而 owner 显示为 `cacfd3a` —— 形状与 r146 记的「**npm 同名不同物**」判据高度相似，因此专门核了一次：
> `GET /repos/digitalheir/bibtex-js` 返回 **301 → `repositories/92252929` → `cacfd3a/bibtex-js`**，
> 即**同一 repo id、同一仓库**，只是 GitHub 用户名从 `digitalheir` 改成了 `cacfd3a`；`fork: false`、`parent: null`。
> **不是陌生人接管**，可以放心。这条也顺带说明：**「npm repository.url 与 owner 不一致」不能单凭字面判为可疑，要先跟一次 301。**
