### 2.1 它是什么（已读源码核实）

- **形态**：Agent Skill（`SKILL.md` + `references/` + **单个 212 KB 的 `zju.py`**），运行方式
  `uv run --script zju.py …`，`runtime: uv`。**纯 Python，没有任何 JS/TS**。
- **做了什么**：把「智云课堂 / 学在浙大」的本地资料库（`~/ZJU-Courses/classroom`）做成**可反查的证据库**：
  1. `classroom subs` —— 列出某门课已同步的**转写 / PPT / 录播**；
  2. **知识点 → 课堂时间**：在转写 Markdown 里检索关键词/同义词，拿到该句的原始起止时间 →「某知识点在 00:01:20 讲过」；
  3. `classroom context --at 00:01:23.120 --window 20` —— 以**任意时间点**回查：该窗口内的转写原文、
     **PPT 候选页**（`created_sec` / `pdf_page` / `event_index` / `relationship`）、音频/视频分段；
  4. `classroom recording-frame --at … --around 4 --interval 2` —— 在**任意时间点取录播真实画面帧**（按需、只读少量）。
- **它的三处「诚实约束」值得本仓抄进设计**（不抄代码，抄判据）：
  - `ppt.created_sec` 是**截图观测点**，不是「该页显示区间」→ 只能称「候选页」；
  - 缺时间的 PPT 事件单列为 `ppt.untimed_events`，**不许强行排进时间窗口**；
  - 多段录播 `--at` 是**段内时间**，缺映射时**不许**从第 1 段猜起。

本仓**没有**的（正是上游多出来的那一段）：

1. **反向**：给定「知识点/关键词」→ 一组带**起止时间**的课堂位置（现在只有搜索 + `atSec`，没有起止区间）；
2. **任意时刻取帧**：给定 `t`，取录播**真实画面**（现在 PPT 是**截图**，`created_sec` 是观测点，动画/多候选时对不上）；
3. **PPT 事件的不确定性建模**：`ppt.events` 的 `relationship` / `selection` / `representative_event_index` / `untimed_events` —— 本仓 `slide()` 把 `createdSec` 当成确定值；
4. **`isKey` 字段被定义但从未使用** —— `grep -rn isKey packages/*/src` **全仓仅 1 处**（`models.js` 定义处），零消费方（同 `recordAttempt` 的「定义即死代码」模式，见第三十七 / 四十四轮）。

**强化式集成三条件**：① 仍是同一个面板 —— 学习页「视频/PPT」栏 ✅；② 功能正交 —— 现在回答「播到 t 是哪页」，上游回答「这一页/这句话在前后哪几段」✅；
③ 底层更优实现 —— **❌ 拿不到**：它是 Python，无法在浏览器/Node 侧调用，而本仓没有任何 Python 运行面（`apps/desktop` 为 Electron，`packages/*` 全 JS）。
→ 三条件**缺一**，故**不得**判 🟢，也不得简单集成。
