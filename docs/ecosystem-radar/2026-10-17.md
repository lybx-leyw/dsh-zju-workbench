**`open-spaced-repetition/fsrs-browser`** —— 本轮**唯一 🟢**，也是本轮 L2 骨架来源。

- **是什么**：FSRS 的**浏览器侧实现**（Rust → WASM），含 **Optimizer**（用个人复习历史训练参数）与 **Scheduler**（计算下次复习时间）。npm 包名 `fsrs-browser`，**零运行时依赖**。
- **为什么是强化而非重复**：本仓**已有** `packages/dsh-radar-fsrs-scheduler`（2026-10-14 第二轮出，锁版 `ts-fsrs@5.4.2`，**仍是候选骨架**）。二者**不是重复**，因为：
  1. **仍是同一个面板** —— 都落在「学习」页（`dsh-zhiyun-page-study`）/ 习题调度，不新开导航项；
  2. **功能仍相似正交** —— `ts-fsrs` 提供**纯算法**（给定卡片状态算间隔）；`fsrs-browser` 额外提供 **WASM 加速的 Optimizer + 浏览器原生运行**，是同一域里「参数从哪来」与「在哪算」的正交问题；
  3. **底层多调了更优质实现** —— 引入本仓**没有**的 WASM 优化器（`ts-fsrs` 无 Optimizer WASM 路径）。
- **与 `ts-fsrs` 的关系澄清**：两者同属 `open-spaced-repetition` 组织，**不是竞品而是分层** —— `fsrs-browser` 面向「浏览器内跑优化」，`ts-fsrs` 面向「纯 TS 算法库」。**建议人工评审时二选一或分层组合**，避免同时接入造成职责重叠（见 §4 风险）。
- **集成方式**：锁版引入 npm `fsrs-browser`（写死版本，不用 `^`）+ 薄封装（能力提取 + 封装，**不搬运上游源码**）。**B 类骨架不含上游 DSH 依赖**。

## 3. 本轮结论

- **C 组「课表导出 / 论文批注」两轴已接近枯竭**：`timetable ics export` 57 条里，符合「JS 栈 + 宽松许可」的仅 4 条，且**全部是单校小工具**（4–34★）；`paper annotation reader` 22 条里已登记的占 5 条，新发现的 4 条**全部 1★ 且建仓不足 2 个月**。
- **C 组「文档解析」轴仍有价值**：`reamkit`（纯 TS、无 LibreOffice 依赖）与 `Trans2Former`（本地 PP-OCRv5）都能强化 `dsh-zhiyun-parser`，但均为小项目（6–10★），**适配成本需人工评估**。
- **本轮最大收获**：`fsrs-browser` —— C 组「复习调度」轴上的 **WASM 优化器**，补上了既有 `dsh-radar-fsrs-scheduler`（纯 TS `ts-fsrs`）缺失的「参数优化」能力。
- **无一条 A 类候选** —— 本轮为 C 组（学生功能域），未涉 DSH 插件生态；A 组待下一轮轮换。

## 4. 建议人工 review 的重点

1. **`fsrs-browser` 与既有 `dsh-radar-fsrs-scheduler` 的关系**（**最高优先**）：二者同属 `open-spaced-repetition` 组织，**是分层而非竞品**。请判定：
   - 方案 ①：**替换** —— 用 `fsrs-browser` 取代 `ts-fsrs`（获得 WASM Optimizer，但引入 WASM 构建链）；
   - 方案 ②：**分层** —— `ts-fsrs` 管纯算法、`fsrs-browser` 管优化器（能力最全，但两个依赖）；
   - 方案 ③：**维持现状** —— 认为 WASM 优化器在当前阶段属过度设计。
   **本骨架按方案 ① 出具**（README 已注明「采用前须裁决与 `ts-fsrs` 的关系」）。
2. **两个候选骨架如何取舍**：`dsh-radar-fsrs-scheduler`（2026-10-14）与 `dsh-radar-fsrs-browser`（本轮）**不应同时采用** —— 否则违反「功能仍相似正交」。
3. **`reamkit` 的适配成本**：纯 TS 无需 LibreOffice 是**显著优势**（本仓若已依赖 headless 转换则有替换价值），但 10★ 项目需评估维护风险。
4. **宽词治理**：`quiz practice app`（2711）与 `fitness tracker javascript`（1069）已饱和，建议后续 C 组改用窄限定词。
5. **`AnimatingAntier/InkRead-AI-paper-reader` 无许可证** —— 功能描述贴合论文场景，但**无许可证即不可采用**，已按硬边界仅登记。
