帧是从横向 sheet 里切的

每张 256×帧数 宽、256 高。播放器只用 drawImage 截一帧，不做缩放变形，清晰度与原图一致。

四种 playback

loop 循环、once 停尾帧、blink 眨眼式、pingpong 来回。按 manifest 里各自的值走，没有写死。
