# 变更日志

`logs/` 按日期记录仓库的结构性变更（改名、迁移、清理等无法从代码直接看出的操作）。

## 组织方式

- **一天一个文件**：`YYYY-MM-DD.md`，当天发生的多条变更都写进同一个文件，最新的在前。
- 文件名用仓库统一时区（`Asia/Shanghai`）的日期。
- 每条记录写清四件事：**做了什么、为什么、怎么验证、怎么回滚**。
- 先读当天的文件；跨天的连续工作各自记在各自日期下。

## 什么时候记

值得记的是"代码里看不出来"的操作：

- 目录 / 包 / profile 改名
- 数据迁移与清理（尤其是删除类）
- 依赖版本的整体切换
- 宿主升级

不需要记的是普通功能改动与缺陷修复 —— 那些有提交历史和 PR。
