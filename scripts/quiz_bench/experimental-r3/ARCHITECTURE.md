# r3：以考法资产为中心的质量与复用

本实验沿已有知识图谱树编译可复用考法。目标是让同一份审查过的材料同时服务出题、讲解与例题，而不把每次请求都当作从头理解整份讲义。当前仍未接入产品。

## 分开评价六件事

1. **原资料**：引文真实存在，与材料内部自洽，仍不等于原资料本身正确。
2. **考法资产**：认知目标、成立条件、推理链和可变因素能否共同构成可靠任务。
3. **实例题**：题干自足、选项互斥，确实落实原任务和指定变体。
4. **解答**：答案、每条解释及错误选项的反驳是否成立。
5. **新增价值**：正确的复习题不等于新增考点；有意义的参数/条件变体也不必是全新原子考点。
6. **复用经济性**：首次编译、共享审查、逐题生成和整改分别计账。

此前人工样本中，r1的18题由11道记忆题和7道理解题组成，分别可用10、5道；r3样本由5道记忆题、13道理解题组成，分别可用4、7道。题干/解析平均长度约从60/107字增为133/230字。难度构成和解释负担不同，但这并不能消除r3自身的推理可靠性问题。需要固定相同任务比较下游变化，不能只比总分。

人工回看r3的7个主试失败项，主因可归为3个上游来源范围/条件/推理问题、2个实例呈现/解释问题、2个变体新增价值问题。这是人工工程归因，不是统计因果估计。

## 资产与执行边界

```text
已有树与完整讲义、页详情
  → 节点所属考法、证据、变体
  → 按需编译共享讲解资产
      条件 + 有来源的推理链 + 易错纠偏 + 已解例题 + 边界备注
  → 独立资产审查：接受 / 整改 / 来源待核
  → 原子预留题目任务，每worker实例化一题
  → 隐去作者答案、解析和考法，独立求解
  → 答案一致性、任务/变体落实、最终解析与跨分支依赖检查
  → 题目写回原节点
```

标题编译及共享资产编译仍读取完整原子树正文和页详情。单题默认只接收对应证据包与树路径目录，需要补充时用原生 `read_material` 读取所属节点子树中的完整材料。资料没有被截断，也不转换成全局语义平面表。

资产的证据使用原位置地址，程序取回原句；推理步骤区分复述和推导，依赖只能指向此前步骤，不能无依据或成环。这些结构约束不能证明推理正确，仍有独立模型审查与最终人工评测。

审查只给一个决定。接受时可保留适用边界等非阻断说明，不得同时声明实质错误；矛盾的工具结果会在原审查阶段澄清。没有来源依据或原文冲突继续挂原任务，不伪造完成。

## 单题独立求解

`submit_solution` 接收实际题干、选项和原文证据，不接收作者答案、解析、考法答案要点或例题。填空标记中的答案也会遮蔽。选择题逐项判真并核对唯一答案；判断/填空核对相应规范答案；简答由独立解答接管参考答案，再检查与任务、条件和评分目标的一致性，不用措辞是否完全相同判对错。

最终检查者知道任务和已经验证的推理，因此不称为盲审。独立求解发生在此之前。工具参数错误只修原工具阶段，不因格式失败重写整题；完整原始调用与回执保留。

## 版本、共享整改与两种书

`createCapsuleStore` 按素材、考法、工具契约和模型缓存域存储共享资产。并发实例共用同一准备任务，后续变体不重复编译已通过资产。待核资产会挂起相应题目，未就绪内容不会进入教材正文。

`requestRepair(ideaId, reason)` 使共享资产进入新版本并保留旧稿和审查历史。依赖旧版本的完成题再次执行前回到原任务整改，不将旧结果冒充新流程验收。原始模式与资产/盲解模式也不允许复用同一完成计划冒充评测结果。

`projectTeachingBooks` 是不调用模型的树形投影：

- **讲解本**：目标、适用条件、推理步骤、易错纠偏、原文证据、边界备注。
- **例题本**：同一资产下的例题、答案、解题步骤。

父子层级和未编译/待整改状态都保留。素材或考法变化后，不导出旧来源的已通过资产。当前只编译实际选中的考法；全量编译需显式准备全部节点考法，不能将按需投影说成全考点已覆盖。当前没有新增教材产品UI。

## 摊还与边界

对同一考法使用N次，可把成本写作：

`总成本 = 考法编译B + 共享资产核查A + Σ(实例化Gᵢ + 独立求解Sᵢ + 复核/整改Rᵢ)`

`平均成本 = (B+A)/N + 平均(G+S+R)`

编译与核查可被摊薄，单题仍有生成、推理与核验成本。显式变体无需每次读全历史来追求正交；新的base任务可读取节点历史，历史处理成本仍需单独考察。复杂变体超出基础证明条件时，重新读取资料和推理并非免费，因此不能用缓存命中宣布整个链路必然是常数token。

下一层重要资产边界是“变体族”：只改参数的绑定和改变成立条件的反例/迁移应分别管理。后者需要可复用的桥接证明，否则会反复扩大材料上下文。当前没有通过降低检查标准来掩盖这部分成本。

## 本轮证据

固定同样两个理解考法、同样三组变体，两个模式各生成6题。原路径完整正确6，资产路径严格5（另1题为题干笔误，放宽6）；保守去重后各有3个有效题组。样本不足以证明质量提升，也不是端到端r1胜负评测。

资产模式只编译/审查两份讲解，后续变体实际复用。后4题token从152,054降到134,456（约11.6%），但等待从42.6秒增至50.4秒。包含首次资产核查的6题总token反而更高，说明当前阶段不能宣布总体更省或更快。

两道例题数值人工复核正确；两份模型通过的讲解中一份纠偏语句过强，已通过共享资产反馈机制挂整改。模型审查通过不是人工质量保证。新增素材因供应商402未完成，迁移与更长使用周期仍待真实验证。保留全部失败和用量，不自动接入产品。
