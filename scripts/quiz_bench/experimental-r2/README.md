# v2-r2：隔离候选实验

产品入口及原包配置不引用本目录。上一候选保存在 `../experimental`，`CANDIDATE.json` 将它命名为 `v2-candidate-r1` 并锁定源码摘要。r2 在同级目录独立迭代，不覆盖 r1。

本轮只改通用机制：

1. 选择题复核先进行独立解答，不提供生成器答案、解释、角度或蓝图答案；安全情况下对选项标签做确定性置换，再映射回来。包含选项间字母引用时保留原顺序。
2. 逐选项核对可成立性，不用“未原样出现在教材”排除等价正确项；独立结论不唯一或与参考答案不一致即返工。通过后再复核解释。
3. 独立解题者输出规范命题、操作、条件与参数，供同知识点查重核对实际任务。每道题必须有 distinct/duplicate/uncertain 判定；正反问法和表面改写不作为新增理由，有效同考点变体仍可保留。
4. 独立解答和解释复核的中间响应分别进入检查点，暂停后可复用，额外模型成本逐次记录。

没有学科名、题目特征匹配、基准专用阈值或特定答案纠错。来源整理和蓝图与 r1 保持一致。新机制主要针对选择题；其他题型沿用 r1 的复核，不能将结果外推为所有题型均改善。

评测纪律：先冻结规则和摘要，再写新的合成留出材料；旧真实素材只作诊断，不再称为未见验证集。新材料不携带人工题目、答案键或历史审计意见。每组同模型、相同 worker 配额、题数和调用上限，交错运行；期间不根据生成结果修改算法。最终正确性、重复与解析质量由助手逐题人工核对，脚本仅汇总账本与人工判定。失败、额外整改、待复核和开发消耗均保留。

DeepTutor 的来源归属沿用 [ATTRIBUTION.md](ATTRIBUTION.md)。r2 的独立盲解、标签映射、结构化查重与中间断点契约是本仓实验实现，不声称复制上游性能。

本轮决定：**不晋级 r2，保留 r1 候选**。两组冻结后新写留出材料中，r1 人工可用 12/12、r2 为 11/12；r2 token 多约 36%，没有证明净收益。单个需补条件题若宽松计入，r2 也只是质量打平、成本更高。完整题稿与人工判定留在忽略的本地评测产物中；不把诊断集上的改善当作泛化证据。
